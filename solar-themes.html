Solar themes for the Innioasis Y1 and Y2

Solar themes are the themes in this gallery. Solar runs the same theme format as Better-Y, Koensayr and the Original Software, so the collection is shared, and Solar can also download a theme directly on the player over Wi-Fi.

What Solar adds to themes

Solar is a custom firmware and launcher for the Innioasis Y1 built around on-device features. For themes, the useful difference is that Solar can browse and download them without a computer: connect the player to Wi-Fi, open the theme browser, preview a theme and install it from there. The same theme is also available here in the gallery if you prefer to download on a computer and transfer it.

Solar themes and the other software

Solar, Better-Y, Koensayr and the Original Software all read the same theme files. A theme you install while running Solar does not stop working if you move to another one of the four, and a theme downloaded from this page works on Solar even though the page is not Solar-specific. There is no conversion step and no Solar-only theme pack.

Solar themes on the Innioasis Y1

The Y1 is the main Solar device and has the largest theme selection. Theme pages show a preview and the available colour variants, and credit the community member who made the theme.

Solar themes on the Innioasis Y2

The Y2 uses the same collection. If you use Solar on a Y2, pick a theme exactly as you would on the Y1; the gallery does not keep a separate Y2 catalogue.

Rockbox themes are separate. A Rockbox player cannot load Solar, Better-Y, Koensayr or Original Software themes. The Rockbox collection is the one to use there.

Three ways to install a Solar theme

  1. On the player: connect Wi-Fi, open Solar's theme browser, choose a theme and download it.
  2. With Updater CE: download the theme on a computer and let Updater CE add it to the player.
  3. By hand: copy the theme into the player's theme folder over USB.

All three are described in the installation guide. More about Solar itself is on the Solar firmware page.

Solar theme questions

Can I download Solar themes without a computer?

Yes. Solar's on-device theme browser downloads themes over Wi-Fi. A computer is only needed if you prefer to transfer files by USB.

Do Solar themes work on Better-Y, Koensayr or the Original Software?

Yes. All four share the theme format, so the same theme works after a software change.

Are Solar themes the same as Rockbox themes?

No. Rockbox has its own format and collection.

Where do I get Solar?

The Solar page explains the firmware, and the firmware archive lists the builds you can install.
