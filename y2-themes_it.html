Temi per Innioasis Y2

Il Innioasis Y2 introduce miglioramenti hardware e aggiornamenti software interni rispetto al classico Y1. Scopri come i temi differiscono tra i modelli e come trovare Y2 pacchetti di temi completi con grafica dedicata al File Manager.

In che modo i temi Y2 differiscono dai temi Y1.

Il software Y2 include un software dedicato Gestore file voce di menu che non esiste nei firmware stock standard Y1. I temi completi Y2 includono grafica dedicata al File Manager, quindi ogni schermata corrisponde.
