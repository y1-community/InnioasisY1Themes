y1-theme-upload Worker — Cloudflare dashboard settings (copy/paste)
====================================================================

Root `wrangler.toml` and `cloudflare-worker-upload.toml` both target
`y1-theme-upload` (`upload-worker.js`) with `workers_dev = true`, so both
`node scripts/deploy-upload-worker.mjs` and bare `npx wrangler deploy` deploy
the upload Worker safely.

Note: `y1-theme-analytics` always deploys with `--config cloudflare-worker-analytics.toml`
(via `scripts/deploy-analytics-worker.mjs`) and ignores root `wrangler.toml`.

Workers & Pages → y1-theme-upload → Settings → Builds & deployments
-------------------------------------------------------------------

  Root directory:     (repository root — leave empty/default so `scripts/` resolves)

  Build command:        exit 0

  Deploy command:       node scripts/deploy-upload-worker.mjs

  Version command:      (leave EMPTY)

Alternative (if Cloudflare runs `npx wrangler deploy` in the Deploy step):

  Build command:        exit 0

  Deploy command:       npx wrangler deploy

After a green build, test:
  https://y1-theme-upload.itsryanspecter.workers.dev/health
  (GET should return 200 {"ok":true,"worker":"y1-theme-upload","configured":true})
  https://y1-theme-upload.itsryanspecter.workers.dev/api/upload-theme
  (OPTIONS should return 204; POST needs multipart from Studio or upload.html)

Free plan note
--------------
  Do not add [limits] cpu_ms or high subrequests in wrangler.toml — deploy fails with
  error 100328 ("CPU limits are not supported for the Free plan"). Defaults apply.

Secrets (Worker → Settings → Variables)
---------------------------------------
  GITHUB_UPLOAD_TOKEN   (required, encrypted)
