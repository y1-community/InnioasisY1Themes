INSTALLEREN OP DE INNIOASIS Y2 (STOCK FIRMWARE)
1. Pak het ZIP-bestand uit op je computer.
2. Sluit de Innioasis Y2 aan via USB-C.
3. Open het interne geheugen en zoek de map "Themes".
4. Kopieer de volledige map "KATSEYE_Luxury_Pink_Bridal_Complete" naar "Themes".
5. Werp de speler veilig uit en koppel hem los.
6. Ga op de Y2 naar Instellingen → Thema en kies "KATSEYE — Luxury Pink Bridal Edition".

BELANGRIJK
Dit pakket volgt de community-documentatie voor de stock-theme-structuur van Y1/Y2. Ik kan het niet fysiek op jouw Y2 testen. Maak eerst een back-up van de bestaande map "Themes". De exacte weergave kan per firmwareversie verschillen.
