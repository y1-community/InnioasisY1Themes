Utilisateurs désinscrits et bloqués

Certains créateurs ne souhaitent pas que leur travail soit répertorié sur theme.innioasis.app. D'autres sont interdits pour abus ou soumissions de mauvaise qualité. Les listes sont conservées dans opt_out.json et block.json.

Auteurs désinscrits

Ces auteurs ont demandé à ce que leurs thèmes ne soient pas soumis ou proposés en téléchargement sur le site Thèmes. Vous pouvez toujours télécharger des packages qui leur sont crédités pour préservation et archivage dans le y1-community/InnioasisY1Themes Dépôt GitHub - les fichiers restent dans les archives de la communauté, mais ils n'apparaîtront pas dans la galerie publique. Les créateurs désinscrits préfèrent généralement héberger leur propre portfolio (boutique, Ko-fi, Patreon, site personnel) et encouragent souvent un Payez ce que vous ressentez modèle de dons plutôt que de les lister ici.

    Aucun auteur n'est actuellement exclu.

    Auteurs bloqués

    Ces auteurs ne sont pas autorisés sur la galerie publique ou via le formulaire de téléchargement. Les thèmes qui leur sont attribués sont cachés aux visiteurs. Les tentatives de téléchargement peuvent encore atteindre GitHub dans certains cas, mais elles ne seront pas répertoriées pour le téléchargement sur thèmes.innioasis.app.
