Rockbox themes for the Innioasis Y1 and Y2

Rockbox themes, including the spelling Rockbox-Themes, are a separate collection. This gallery hosts themes for the Original Software, Better-Y, Koensayr and Solar. A Rockbox theme will not install as one of those.

Rockbox themes for the Innioasis Y1

Innioasis Y1 Rockbox themes, also called Rockbox Y1 themes and Rockbox skins for the Y1, come from the Y1 Rockbox theme pack. The Rockbox button on the gallery opens that pack.

Open the Y1 Rockbox theme pack

Rockbox themes for the Innioasis Y2

Innioasis Y2 Rockbox themes ship with the Y2 Rockbox install, not with the themes in this gallery. Install Rockbox from Updater CE, then use the themes that release includes.

Themes for the other systems

If the player is running the Original Software, Better-Y, Koensayr or Solar, use this gallery. themes.rockbox.org is the catalogue for other Rockbox players.
