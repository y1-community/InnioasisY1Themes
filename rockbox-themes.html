Rockbox themes and Rockbox-Themes for the Innioasis Y1 and Y2

This is the Rockbox collection in the Themes Gallery. Rockbox themes, sometimes written Rockbox-Themes, use their own format and are not interchangeable with the Better-Y, Koensayr, Solar and Original Software themes on the rest of the site.

Rockbox themes are a separate format

The other four software options for the Innioasis Y1 and Y2 share one theme format, so a theme can move between them. Rockbox is different. Its themes are built for Rockbox itself, with Rockbox's own file layout, and a Rockbox player cannot load a theme from the shared gallery collection. The reverse is also true: a Better-Y, Koensayr, Solar or Original Software player cannot load a Rockbox theme.

That is why this page exists as its own collection instead of being mixed into the main grid. It is the same gallery, with a separate shelf for a separate format.

Rockbox themes on the Innioasis Y2

Rockbox themes in this collection are also listed for the Y2. If a theme has a note about a particular device or screen, the theme page says so.

Installing a Rockbox theme

Rockbox themes are installed through Rockbox's own theme directory, not through the shared theme installer used for the other four software options. The theme page for the one you pick includes the file and any notes from its author. If you are switching a player to Rockbox for the first time, start from the firmware archive, which covers the Rockbox build and its requirements.

Rockbox theme questions

Are Rockbox themes compatible with Better-Y, Koensayr, Solar or the Original Software?

No. Rockbox has its own theme format, and the shared themes do not load in Rockbox either.

Why are Rockbox themes listed separately?

They are a different format with different installation rules. A separate collection prevents a theme being installed on software that cannot read it.

Do Rockbox themes work on both the Y1 and Y2?

Themes in this collection are listed for the Y1 and Y2. Check the theme page for device-specific notes.

Can I use a Rockbox theme on a player that is not running Rockbox?

No. Install Rockbox first, then use the Rockbox theme collection.
