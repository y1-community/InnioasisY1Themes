STARLIGHT POP CLUB — Innioasis Y2 fan theme
A colorful theme pack inspired by KATSEYE, Wicked, Olivia Rodrigo, Ariana Grande, ADÉLA, ILLIT and DARA.
The pictures are original decorative fan-art-style graphics and are not official artist photos or logos.

VIEW PREVIEW
Open the companion preview image: Starlight_Pop_Mix_Y2_preview.png

INSTALL
1. Extract this ZIP so you have a folder named Starlight_Pop_Mix_Y2_v2.
2. Check the community gallery/editor instructions for the current Y2 workflow:
   https://themes.innioasis.app/
   https://themes.innioasis.app/creators/
3. Use the editor's preview and export features if required. Do not install an untested pack blindly; firmware/editor compatibility can vary.
4. The creator guide documents the theme structure, config.json, cover.png and the image sizes. Keep config.json and cover.png at the top level of the theme folder.

This package has a theme config and assets referenced by that config, but has not been tested on a physical Y2 device.
