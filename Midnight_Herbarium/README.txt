Midnight Herbarium — Innioasis Y1 Theme
========================================

Based on the supplied 320x240 artwork.

Install:
1. Unzip this folder.
2. Copy the "Midnight_Herbarium" folder into the Y1's Themes folder:
   /storage/sdcard0/Themes/
3. On the Y1, open Settings > Themes and select Midnight Herbarium.

This pack targets the stock Y1 theme system. The wallpaper is 480x360,
and the main menu icons use the Y1's 150x166 icon dimensions.
