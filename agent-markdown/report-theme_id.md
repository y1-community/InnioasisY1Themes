# Laporkan masalah tema

Gunakan formulir ini untuk kekhawatiran tentang tema galeri tertentu (misalnya gambar yang tidak pantas, hak cipta, file berbahaya, atau kredit yang menyesatkan). Jika Anda adalah penulisnya dan ingin tema Anda dihapus, pilih alasan untuk tidak ikut serta dan kami akan mengarahkan Anda ke alur permintaan penghapusan.Terima kasih - laporan Anda telah terkirim.Jika Anda meninggalkan alamat email, Anda akan menerima konfirmasi singkat dari penyedia formulir kami. Kami tidak selalu dapat membalas satu per satu.Penyisihan penulis didukung. Jika Anda tidak ingin tema Anda tercantum di sini, pilih “Saya tidak ingin tema saya ada di sini” dalam jenis laporan. Kami akan mengirim Anda langsung ke permintaan penghapusan untuk verifikasi. 

### Rute penghapusan penulis

Jenis laporan ini ditujukan untuk tidak ikut serta oleh penulis, jadi kami memindahkan Anda ke alur penghapusan terverifikasi.
