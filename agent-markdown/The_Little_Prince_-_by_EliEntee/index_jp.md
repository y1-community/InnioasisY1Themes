# The Little Prince - by EliEntee

EliEntee

Innioasis Y1 の星の王子さまのテーマは、音楽プレーヤーに暖かく魔法のような雰囲気をもたらします。星の王子さまの時代を超えた物語にインスピレーションを得たこの製品は、柔らかな色、エレガントなアイコン、夢のようなファンタジーにインスピレーションを得たデザインを組み合わせて、心地よくノスタルジックなリスニング体験を生み出します。
