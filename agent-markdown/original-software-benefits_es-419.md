# Software original para reproductores Innioasis y Timmkoo

Software original is the official factory operating system shipped on Innioasis and Timmkoo portable players. It provides rock-solid hardware stability, full support for custom skins from the [Galería de temas](https://themes.innioasis.app/?lang=es-419), FM radio, Bluetooth audio streaming, audiobook progress saving, and safe factory restore via Innioasis Updater CE.[Explorar descargas de software](firmware.html)[Obtener Updater CE](guide.html#platform)[Explorar la galería de temas](https://themes.innioasis.app/?lang=es-419)

## ¿Por qué utilizar o restaurar software original?

### Soporte completo de la galería de temas

El software original en Y1 y Y2 funciona directamente con máscaras personalizadas del [Galería de temas](https://themes.innioasis.app/?lang=es-419). Cambie íconos, fondos de pantalla, diales de reproductor y fuentes sin modificar las particiones centrales del sistema.

### Todo funciona desde el primer momento

Soporte completo para auriculares Bluetooth y audio para automóvil, navegación física con rueda de clic, sintonización de radio FM por hardware, marcadores de audiolibros, libros electrónicos y reproducción de video sin configuración manual.

### Recuperación segura y línea de base para desbloquear

Si alguna vez desea revertir un experimento de firmware personalizado o recuperar un reproductor que no arranca, Updater CE restaura el software original en un solo paso guiado.
