# Abgemeldete und blockierte Benutzer

 Einige Ersteller möchten nicht, dass ihre Arbeit auf themes.innioasis.app aufgeführt wird. Andere werden wegen Missbrauch oder minderwertiger Einsendungen gesperrt. Listen werden in gepflegt [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) und [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## Abgemeldete Autoren

 Diese Autoren haben darum gebeten, dass keine Themen auf der Themenseite eingereicht oder zum Download angeboten werden. Sie können weiterhin Pakete hochladen, die ihnen gutgeschrieben wurden Konservierung und Archivierung im [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub Repository – Dateien bleiben im Community-Archiv, werden aber nicht in der öffentlichen Galerie angezeigt. Abgemeldete Ersteller bevorzugen in der Regel das Hosten ihres eigenen Portfolios (Shop, Ko-fi, Patreon, persönliche Website) und ermutigen häufig dazu, ein eigenes Portfolio zu hosten Zahlen Sie, was Sie fühlen Spendenmodell, anstatt hier aufzulisten. 

Derzeit sind keine Autoren abgemeldet.

## Gesperrte Autoren

 Diese Autoren sind weder in der öffentlichen Galerie noch über das Upload-Formular zugelassen. Ihnen zugeschriebene Themen bleiben den Besuchern verborgen. In einigen Fällen erreichen Upload-Versuche möglicherweise immer noch GitHub, sie werden jedoch nicht zum Download auf themes.innioasis.app aufgeführt. 

Derzeit sind keine Autoren blockiert.

Autorenlisten konnten nicht geladen werden. Versuchen Sie es später noch einmal.
