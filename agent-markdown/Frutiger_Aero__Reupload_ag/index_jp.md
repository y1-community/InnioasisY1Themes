# Frutiger Aero

AG

素晴らしいfrutigerエアロテーマ。 Rockbox の XP テーマのコンセプトに部分的に基づいているか、それにインスピレーションを受けています。 (テーマが削除されたため、以前にたくさんの反響をいただいたので再アップロードしなければなりませんでした!) メンテナー / ギャラリー MOD からのメッセージ: 申し訳ありませんが、テーマが Frutiger Aero という別の提出物によって上書きされました。これを防ぐための取り込みプロセスには安全策が設けられていますが、ユーザーが既存のテーマの更新としてマークした可能性があり、レビュー中にフラグが付けられるべきでした。
