# 选择退出并阻止用户

 一些创作者不希望他们的作品出现在 theme.innoasis.app 上。其他人则因滥用或低质量提交而被禁止。列表维护在 [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) 和 [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## 选择退出的作者

 这些作者要求不要在主题网站上提交或提供下载主题。您仍然可以上传记入他们的包 保存和归档 在 [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub 存储库 - 文件保留在社区存档中，但不会出现在公共图库中。选择退出的创作者通常更喜欢托管自己的作品集（商店、Ko-fi、Patreon、个人网站），并经常鼓励 付出你的感受 捐赠模型而不是在这里列出。 

目前没有作者选择退出。

## 被屏蔽的作者

 这些作者不允许出现在公共画廊或通过上传表单。他们的主题对访客是隐藏的。在某些情况下，上传尝试可能仍会达到 GitHub，但它们不会在 theme.innioasis.app 上列出以供下载。 

目前没有作者被屏蔽。
