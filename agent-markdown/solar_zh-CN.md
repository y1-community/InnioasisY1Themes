# 所需测试人员：Solar 用于 Y1

 Solar 在您的 Y1 上启用 Wi-Fi，并在您的 Innioasis Y1 上解锁现代功能的世界 - 从直接设备上主题下载和无广告流媒体到可视化 Cover Flow 浏览。 [ 创建者： 太阳能计划](https://github.com/thesolarproject)[ 查看 GitHub 上的 Solar ](https://github.com/thesolarproject/solar)[ 如何安装 ](#install)[ 浏览主题 ](index_zh-CN.html)

## Solar 给 Y1 带来什么

 Solar 是 Innioasis Y1 的完整界面替代品和现代操作系统，支持 Wi-Fi 和直接设备上网络工具。 

### 直接主题下载

通过 Wi-Fi 下载此库中的主题并将其应用到您的 Y1 上。无需 PC、浏览器或 USB 传输。

### 无广告 YouTube

直接在播放器上流式传输或下载离线 YouTube 视频和高品质音轨，完全没有广告。

### 达到（Deezer 和 Soulseek）

使用 Deezer 会话（无广告的 MP3/FLAC）或 Soulseek P2P 共享直接通过 Wi-Fi 搜索、播放和下载音乐。

### 流量相册浏览

直接在设备上体验流畅的 Cover Flow 风格的视觉专辑导航，带来直观、复古的音乐感觉。

### 播客和导航场

通过互联网搜索并下载最喜爱的播客剧集，或连接到您自己的个人自托管 Navidrome 库。

### 无线更新

直接通过 Wi-Fi 从设备设置接收并安装未来的 Solar 更新，无需插入 PC。

### 全局快捷菜单

从任何屏幕访问全局上下文菜单，即可立即控制播放、队列管理、Wi-Fi 和蓝牙设置。

### 完整的主题兼容性

100% 兼容本网站的所有社区主题。保持您的自定义外观，同时解锁现代操作系统功能。

## 如何安装 Solar

 在官方 Innioasis 更新应用程序中，在 Innioasis Y1 上安装 Solar 既快速又简单。 
  - 1打开 Innioasis 更新程序

在您的计算机上启动官方 Innioasis 更新程序工具
  - 2从软件下拉列表中选择 Solar

挑选 Solar 直接从 软件 更新程序中的下拉列表。
  - 3单击安装

击中 安装 按钮。更新程序将自动下载固件并刷新 Solar 到您的设备。
笔记： Solar 目前正在进行 alpha 测试并且 [@TheSolarProject 需要您的反馈](https://github.com/thesolarproject/solar/issues)。安装后，可以直接通过 Wi-Fi 下载和应用未来的更新，而无需使用计算机。 Y2 支持即将推出。

### 替代安装方法

通过更新程序手动压缩： 下载最新的 `rom.zip` 从 [Solar GitHub 发布](https://github.com/thesolarproject/solar/releases/latest) 页面，点击 浏览文件 在 Innioasis Updater 中，选择下载的 zip 文件开始安装。 

 高级用户还可以使用以下命令刷新 Solar SP Flash Tool 5.1924 或 MTKClient。有关完整的刷新说明和开发人员文档，请访问 [Solar 项目文档](https://github.com/thesolarproject/solar#readme-ov-file).
