# InnoPod Rev.2

Kyoukopilled

これは、このプラットフォーム向けでこれまでで最も正確な iPod テーマです。 iPod Classic に似た体験を求める人のために、「iPod っぽい」テーマに基づいて iPod のユーザー インターフェイスを再現しました。 個人的には、ホームページの壁紙を自分の選択したアルバム アートに変更することをお勧めします。オリジナルではそうしていたものです。 名前の「Rev.2」は、iPod Classic にはない、特定のメニューのアイコンを表示するというテーマの現代的な解釈を表しています。
