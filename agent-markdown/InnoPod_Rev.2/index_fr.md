# InnoPod Rev.2

Kyoukopilled

Il s’agit du thème iPod le plus précis à ce jour pour cette plateforme. Pour ceux qui souhaitent une expérience similaire à celle des iPod Classics, j'ai recréé l'interface utilisateur d'un iPod, basée sur le thème "iPod-ish". Personnellement, je vous recommande de remplacer le fond d'écran de la page d'accueil par une pochette d'album de votre choix, car c'est ce que l'original a fait. Le "Rev.2" dans le nom signifie une version moderne du thème, qui affiche les icônes de certains menus, ce que l'iPod Classic ne fait pas.
