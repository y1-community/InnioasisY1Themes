# InnoPod Rev.2

Kyoukopilled

Este es el tema de iPod más preciso para esta plataforma hasta el momento. Para aquellos que desean una experiencia similar a la del iPod Classics, recreé la interfaz de usuario de un iPod, basada en el tema "iPod-ish". Personalmente, te recomiendo que cambies el fondo de pantalla de la página de inicio por la carátula del álbum de tu elección, ya que eso es lo que hacía el original. El "Rev.2" en el nombre significa una versión moderna del tema, que muestra los íconos de ciertos menús, algo que el iPod Classic no hace.
