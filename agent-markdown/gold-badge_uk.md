# Теми, яким можна довіряти на своїх Y1 і Y2

 Коли ви бачите золото в галереї, ця тема готова для Innioasis Y1 або Y2, які ви маєте сьогодні. Менше здогадок, більше впевненості, перш ніж торкнутися завантаження. [ Перегляньте теми Gold](index_uk.html?gold=1)

## Що золото означає для вас

### Готовий зараз

Створено для програмного забезпечення на вашому плеєрі сьогодні, тому все працює так, як ви очікуєте.

### Повна картина

Охоплює додаткові екрани, які нам важливі, а не лише шпалери для дому.

### Один простий сигнал

Той самий золотий значок у галереї та на цій сторінці. Легко помітити, легко довіряти.

## Як ми вирішимо

 Золото є знаком якості спільноти, а не гарантією. Ми автоматично перевіряємо кожну тему, щоб значок відповідав тому, що є в пакеті. Якщо майбутнє оновлення Y1 або Y2 щось порушує, значок може зникнути, доки це не буде виправлено. Технічні деталі (для розробників тем)

Тема отримує золото, коли вона проходить нашу перевірку сумісності з ілюстраціями (так само, як значок галереї):
  - `config.json` містить перелік шляхів для перемикача Rockbox запуску, пристрою для читання електронних книг, калькулятора та календаря.
  - Кожен пов’язаний файл існує і є справжнім твором мистецтва – ні `transparent.png` або `backfill.png` заповнювачі на `launcher.png`, `calendar.png`, `ebook.png`, або `calculator.png`.
  - Автори можуть встановити `gallery.compatibilityMedal` для `gold` або `none` щоб примусово ввімкнути або вимкнути значок.

 Теми перевіряються пакетами, коли ви відкриваєте цю сторінку або галерею. Для завантаження абсолютно нових даних може знадобитися деякий час, перш ніж з’явиться золото. 

 Завжди створюйте резервну копію Y1 або Y2 перед встановленням будь-якої теми.
