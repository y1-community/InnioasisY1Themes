# Valgte bort og blokkerte brukere

 Noen skapere vil ikke at arbeidet deres skal være oppført på themes.innioasis.app. Andre er utestengt for misbruk eller innsendinger av lav kvalitet. Lister opprettholdes i [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) og [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## Forfattere som har valgt bort

 Disse forfatterne har bedt om å ikke få temaer sendt eller tilbudt for nedlasting på temasiden. Du kan fortsatt laste opp pakker som er kreditert dem for bevaring og arkivering i [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub repository – filer blir værende i fellesskapsarkivet, men de vil ikke vises i det offentlige galleriet. Utvalgte skapere foretrekker vanligvis å være vert for sin egen portefølje (butikk, Ko-fi, Patreon, personlig side) og oppmuntrer ofte til en Betal det du føler donasjonsmodell i stedet for å liste her. 

Ingen forfattere er foreløpig valgt bort.

## Blokkerte forfattere

 Disse forfatterne er ikke tillatt på det offentlige galleriet eller gjennom opplastingsskjemaet. Temaer som krediteres dem, er skjult for besøkende. Opplastingsforsøk kan fortsatt nå GitHub i noen tilfeller, men de vil ikke bli oppført for nedlasting på themes.innioasis.app. 

Ingen forfattere er blokkert for øyeblikket.

Kunne ikke laste inn forfatterlister. Prøv igjen senere.
