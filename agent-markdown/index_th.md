# ธีมส์

แกลเลอรีธีมสำหรับ Innioasis Y1 และ Y2 ที่สร้างโดยชุมชน ดูตัวอย่างธีมก่อนที่จะติดตั้งหรืออัปโหลดธีมที่คุณสร้างขึ้น[ อัปโหลดธีม](upload_th.html)[ Rockbox ธีม](https://innioasis.app/rockbox-y1-themes.html?utm_source=themes.innioasis.app&utm_medium=referral&utm_campaign=rockbox_themes&ref=themes_gallery&what=theme&resolution=360p)ติดตั้งโดยตรงติดตั้งโดยตรงไปที่ Y1 หรือ Y2 ของคุณ - เลือกโฟลเดอร์ธีมของผู้เล่น โดยไม่ต้องดาวน์โหลดไฟล์ zipเลือกโฟลเดอร์ธีม เลือกโฟลเดอร์แล้วอัปเดตทั้งหมดบน Y1  แสดงเฉพาะธีมที่มีอยู่แล้วใน Y1  แหล่งที่มา ธีมทั้งหมดแพ็คเกจแกลลอรี่ลิงค์ภายนอก ผู้เขียน ผู้เขียนทุกคนชัดเจน เรียงลำดับ ชื่อ (ก-ฮ)ชื่อ (จ-ก)ผู้แต่ง (ก-ฮ)ยอดวิวมากที่สุดยอดดูน้อยที่สุดดาวน์โหลดมากที่สุดดาวน์โหลดน้อยที่สุดคะแนนสูงสุดคะแนนต่ำสุด ต่อหน้า 122448 ทองเท่านั้น ไม่มีธีมที่ตรงกับตัวกรองปัจจุบันของคุณ

## อัปเดตธีมทั้งหมดใน Y1

รีเฟรชทุกธีมที่อยู่ใน Y1 ของคุณด้วยไฟล์ล่าสุดจากแกลเลอรีนี้ ไม่ได้ติดตั้งธีมใหม่ - ให้ใช้การติดตั้งโดยตรงบนการ์ดแต่ละใบก่อนพร้อมที่จะเริ่มต้นยกเลิกเริ่มการอัพเดต
