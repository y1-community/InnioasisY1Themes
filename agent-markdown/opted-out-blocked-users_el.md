# Εξαιρούνται και αποκλεισμένοι χρήστες - Innioasis Y1 &amp; Y2 Θέματα

[Y1 & Y2 Θέματα](https://themes.innioasis.app/index.html?lang=el)[Συντάκτης](https://y1-themes.vercel.app)[Μεταφόρτωση](https://themes.innioasis.app/upload.html?lang=el)

# Εξαίρεση και αποκλεισμός χρηστών

 Ορισμένοι δημιουργοί δεν θέλουν το έργο τους να αναφέρεται στο themes.innioasis.app. Άλλοι απαγορεύονται για κατάχρηση ή υποβολές χαμηλής ποιότητας. Οι λίστες διατηρούνται σε [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) και [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## Συγγραφείς που έχουν εξαιρεθεί

 Αυτοί οι συγγραφείς έχουν ζητήσει να μην υποβληθούν ή να προσφερθούν θέματα για λήψη στον ιστότοπο Themes. Μπορείτε ακόμα να ανεβάσετε πακέτα που πιστώθηκαν σε αυτά διατήρηση και αρχειοθέτηση στο [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub αποθετήριο - τα αρχεία παραμένουν στο αρχείο της κοινότητας, αλλά δεν θα εμφανιστούν στη δημόσια συλλογή. Οι δημιουργοί που έχουν εξαιρεθεί συνήθως προτιμούν να φιλοξενούν το δικό τους χαρτοφυλάκιο (κατάστημα, Ko-fi, Patreon, προσωπικός ιστότοπος) και συχνά ενθαρρύνουν ένα Πληρώστε αυτό που νιώθετε μοντέλο δωρεών αντί να καταχωρίσετε εδώ. 

Κανένας συντάκτης δεν έχει εξαιρεθεί αυτήν τη στιγμή.

## Αποκλεισμένοι συγγραφείς

 Αυτοί οι συγγραφείς δεν επιτρέπονται στη δημόσια συλλογή ή μέσω της φόρμας μεταφόρτωσης. Τα θέματα που τους πιστώνονται είναι κρυμμένα από τους επισκέπτες. Οι προσπάθειες μεταφόρτωσης ενδέχεται να εξακολουθούν να φθάνουν το GitHub σε ορισμένες περιπτώσεις, αλλά δεν θα αναφέρονται για λήψη στο themes.innioasis.app. 

Κανένας συντάκτης δεν έχει αποκλειστεί αυτήν τη στιγμή.

Δεν ήταν δυνατή η φόρτωση λιστών συγγραφέων. Δοκιμάστε ξανά αργότερα.
