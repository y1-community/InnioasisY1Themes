# Теми для Innioasis Y2

Innioasis Y2 представляє вдосконалення обладнання та внутрішні оновлення програмного забезпечення порівняно з класичним Y1. Дізнайтеся, чим відрізняються теми між моделями та як знайти повні Y2 пакети тем із спеціальним оформленням Диспетчера файлів.

## Чим теми Y2 відрізняються від тем Y1.

Програмне забезпечення Y2 містить спеціальний Менеджер файлів пункт меню, якого немає в стандартних Y1 прошивках. Повні Y2 теми включають спеціальне оформлення диспетчера файлів, тому кожен екран відповідає.[Перегляньте перевірені Y2 теми](index_uk.html?filter=y2)[Завантажте Y2 тему](upload_uk.html)
