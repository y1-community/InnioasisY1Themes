# Ilmoita teemaongelmasta

Käytä tätä lomaketta, jos olet huolissasi tietystä gallerian teemasta (esimerkiksi sopimattomat kuvat, tekijänoikeudet, haitalliset tiedostot tai harhaanjohtavat tekijät). Jos olet kirjoittaja ja haluat poistaa oman teemasi, valitse kieltäytymisen syy, niin ohjaamme sinut poistopyyntöprosessiin.Kiitos - raporttisi lähetettiin.Jos jätit sähköpostiosoitteen, sinun pitäisi saada lyhyt vahvistus lomaketoimittajaltamme. Emme voi aina vastata henkilökohtaisesti.Tekijän kieltäytymistä tuetaan. Jos et halua, että teemasi luetellaan tässä, valitse "En halua teemaani tänne" raporttityypissä. Lähetämme sinulle suoraan poistopyyntöön vahvistusta varten. 

### Tekijän poistoreitti
