# Innioasis Y2 的主题

Innioasis Y2 在经典 Y1 的基础上引入了硬件增强和内部软件更新。了解模型之间的主题有何不同，以及如何找到带有专用文件管理器图稿的完整 Y2 主题包。

## Y2 主题与 Y1 主题有何不同

Y2 软件包括一个专用的 文件管理器 标准 Y1 库存固件中不存在的菜单项。完整的 Y2 主题包括专用的文件管理器图稿，因此每个屏幕都匹配。[浏览已验证的 Y2 主题](index_zh-CN.html?filter=y2)[上传 Y2 主题](upload_zh-CN.html)
