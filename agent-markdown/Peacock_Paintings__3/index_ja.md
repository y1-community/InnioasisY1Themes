# Peacock Paintings <3

Alex_Mtz

これは古い絵画の美学と新聞アートのテーマですが、孔雀が登場します。 私と同じようにティールブルーの Innioasis を使用している人には、このテーマを強くお勧めします。 MP3 がどのようなものかを Instagram に投稿しました。このテーマをお楽しみいただければ幸いです。私はこのテーマを愛と思いやりを持って作りました。 これを完了するのに 2 日、おそらく 3 日かかりました。これを作ったときは MP3 さえ持っていなかったので、まだ発送中でした。私に作るテーマをリクエストしたい場合は、私のインスタグラムからすぐにアクセスできます。 <3.
