# Relatar um problema de tema

Use este formulário para preocupações sobre um tema específico da galeria (por exemplo, imagens inadequadas, direitos autorais, arquivos prejudiciais ou créditos enganosos). Se você é o autor e deseja que seu próprio tema seja removido, escolha o motivo da desativação e nós o encaminharemos para o fluxo de solicitação de remoção.Obrigado – seu relatório foi enviado.Se você deixou um endereço de e-mail, deverá receber uma breve confirmação do nosso provedor de formulário. Nem sempre podemos responder individualmente.A desativação do autor é suportada. Se você não quiser que seu tema seja listado aqui, selecione “Não quero meu tema aqui” no tipo de relatório. Iremos encaminhá-lo diretamente para a solicitação de remoção para verificação. 

### Rota de remoção de autor

Este tipo de relatório é para desativação do autor, por isso transferimos você para o fluxo de remoção verificada.
