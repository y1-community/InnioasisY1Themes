# Melden Sie ein Theme-Problem

Verwenden Sie dieses Formular, wenn Sie Bedenken zu einem bestimmten Galeriethema haben (z. B. unangemessene Bilder, Urheberrecht, schädliche Dateien oder irreführende Quellennachweise). Wenn Sie der Autor sind und möchten, dass Ihr eigenes Theme entfernt wird, wählen Sie den Opt-out-Grund aus und wir leiten Sie zum Ablauf der Entfernungsanforderung weiter.Vielen Dank – Ihr Bericht wurde gesendet.Wenn Sie eine E-Mail-Adresse hinterlassen haben, sollten Sie eine kurze Bestätigung von unserem Formularanbieter erhalten. Wir können nicht immer individuell antworten.Die Abmeldung des Autors wird unterstützt. Wenn Sie nicht möchten, dass Ihr Thema hier aufgeführt wird, wählen Sie es aus „Ich möchte mein Thema hier nicht haben“ im Berichtstyp. Wir leiten Sie zur Überprüfung direkt zur Entfernungsanfrage weiter. 

### Route zum Entfernen des Autors

Da es sich bei diesem Berichtstyp um die Deaktivierung durch Autoren handelt, haben wir Sie zum verifizierten Entfernungsprozess weitergeleitet.
