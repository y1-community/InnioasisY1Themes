# Valde bort och blockerade användare

 Vissa kreatörer vill inte att deras verk ska listas på themes.innioasis.app. Andra är förbjudna för missbruk eller inlägg av låg kvalitet. Listor upprätthålls i [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) och [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## Utvalda författare

 Dessa författare har bett om att inte få inlämnade teman eller erbjudas för nedladdning på Temawebbplatsen. Du kan fortfarande ladda upp paket som krediteras dem för bevarande och arkivering i [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub arkiv – filer finns kvar i communityarkivet, men de kommer inte att visas i det offentliga galleriet. Skapare som valts bort föredrar vanligtvis att vara värd för sin egen portfölj (butik, Ko-fi, Patreon, personlig webbplats) och uppmuntrar ofta en Betala vad du känner donationsmodell istället för att lista här. 

Inga författare är för närvarande bortvalda.

## Blockerade författare

 Dessa författare är inte tillåtna på det offentliga galleriet eller genom uppladdningsformuläret. Teman som krediteras dem är dolda för besökare. Uppladdningsförsök kan fortfarande nå GitHub i vissa fall, men de kommer inte att listas för nedladdning på themes.innioasis.app. 

Inga författare är för närvarande blockerade.

Det gick inte att ladda författarlistor. Försök igen senare.
