# テーマの問題を報告する

特定のギャラリーのテーマ (不適切な画像、著作権、有害なファイル、誤解を招くクレジットなど) に関する懸念がある場合は、このフォームを使用してください。あなたが作成者で、独自のテーマの削除を希望する場合は、オプトアウトの理由を選択してください。削除リクエストのフローに進みます。ありがとうございます。レポートは送信されました。電子メール アドレスを残した場合は、フォーム プロバイダーから短い確認メールが届きます。個別にご返信できない場合もございます。作成者のオプトアウトがサポートされています。 テーマをここにリストしたくない場合は、選択してください 「自分のテーマをここに載せたくない」 レポートタイプで。確認のため、削除リクエストを直接お送りします。
