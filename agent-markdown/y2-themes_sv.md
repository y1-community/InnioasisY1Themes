# Teman för Innioasis Y2

Innioasis Y2 introducerar hårdvaruförbättringar och interna mjukvaruuppdateringar jämfört med den klassiska Y1. Lär dig hur teman skiljer sig mellan modeller och hur du hittar kompletta Y2 temapaket med dedikerade filhanterare.

## Hur Y2 teman skiljer sig från Y1 teman

Programvaran Y2 inkluderar en dedikerad Filhanteraren menypost som inte finns i standard Y1 lagerfirmware. Fullständiga Y2 teman inkluderar dedikerade filhanterarekonstverk, så varje skärm matchar.[Bläddra Verifierade Y2 teman](index_sv.html?filter=y2)[Ladda upp ett Y2-tema](upload_sv.html)
