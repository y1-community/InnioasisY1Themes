# Innioasis Y2 的主題

Innioasis Y2 在經典 Y1 的基礎上引入了硬體增強和內部軟體更新。了解模型之間的主題有何不同，以及如何找到專用文件管理器圖稿的完整 Y2 主題包。

## Y2 主題與 Y1 主題有何不同

Y2 軟體包含一個專用的 文件管理器 標準 Y1 庫存韌體中不存在的選單項目。完整的 Y2 主題包括專用的文件管理器圖稿，因此每個畫面都匹配。[瀏覽已驗證的 Y2 主題](index_zh-TW.html?filter=y2)[上傳 Y2 主題](upload_zh-TW.html)
