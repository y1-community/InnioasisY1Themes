# Signaler un problème de thème

Utilisez ce formulaire pour toute préoccupation concernant un thème spécifique de la galerie (par exemple, images inappropriées, droits d'auteur, fichiers nuisibles ou crédits trompeurs). Si vous êtes l'auteur et souhaitez que votre propre thème soit supprimé, choisissez le motif de désinscription et nous vous dirigerons vers le flux de demande de suppression.Merci - votre rapport a été envoyé.Si vous avez laissé une adresse e-mail, vous devriez recevoir une courte confirmation de notre fournisseur de formulaire. Nous ne pouvons pas toujours répondre individuellement.La désinscription de l'auteur est prise en charge. Si vous ne souhaitez pas que votre thème soit répertorié ici, sélectionnez "Je ne veux pas de mon thème ici" dans le type de rapport. Nous vous enverrons directement la demande de suppression pour vérification. 

### Itinéraire de suppression de l'auteur

Ce type de rapport est destiné à la désinscription des auteurs. Nous vous avons donc transféré vers le flux de suppression vérifiée.
