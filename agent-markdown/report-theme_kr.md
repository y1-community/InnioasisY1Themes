# 테마 문제 신고

특정 갤러리 주제(예: 부적절한 이미지, 저작권, 유해한 파일 또는 오해의 소지가 있는 크레딧)에 대한 우려 사항이 있는 경우 이 양식을 사용하세요. 귀하가 작성자이고 자신의 테마를 제거하려는 경우, 거부 이유를 선택하면 제거 요청 흐름으로 연결됩니다.감사합니다. 보고서가 전송되었습니다.이메일 주소를 남겨두셨다면 양식 제공자로부터 간단한 확인 메시지를 받으셔야 합니다. 항상 개별적으로 답변을 드릴 수는 없습니다.작성자 제외 기능이 지원됩니다. 여기에 테마를 나열하지 않으려면 다음을 선택하세요. "여기서 내 테마를 적용하고 싶지 않습니다." 보고서 유형에서. 확인을 위해 삭제요청을 직접 보내드립니다. 

### 작성자 삭제 경로

이 보고서 유형은 작성자 선택 해제를 위한 것이므로 확인된 삭제 흐름으로 이동되었습니다.

[공개 제거 요청](https://themes.innioasis.app/upload.html?mode=remove&lang=ko)[보고서 양식 유지](https://themes.innioasis.app/report-theme.html?lang=ko)귀하의 이메일 (필수의)
