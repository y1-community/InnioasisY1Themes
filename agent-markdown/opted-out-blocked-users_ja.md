# オプトアウトおよびブロックされたユーザー

 クリエイターの中には、自分の作品が Themes.innioasis.app に掲載されることを望まない人もいます。悪用または低品質の投稿のために禁止されるものもあります。リストは次の場所で管理されます [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) そして [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## オプトアウトされた著者

 これらの作成者は、テーマ サイトでテーマを送信したり、ダウンロードのために提供したりしないように求めています。クレジットが記載されたパッケージは引き続きアップロードできます 保存とアーカイブ で [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub リポジトリ - ファイルはコミュニティ アーカイブに残りますが、パブリック ギャラリーには表示されません。オプトアウトしたクリエイターは通常、自分のポートフォリオ (ショップ、Ko-fi、Patreon、個人サイト) をホストすることを好み、多くの場合、 感じたことを支払ってください ここにリストするのではなく、寄付モデルです。 

現在オプトアウトしている著者はいません。

## ブロックされた著者

 これらの著者は、公開ギャラリーやアップロード フォームを使用することを許可されていません。彼らがクレジットしたテーマは訪問者には隠されています。場合によっては、アップロード試行が引き続き GitHub に達する場合がありますが、これらは、themes.innioasis.app でダウンロード用にリストされません。 

現在ブロックされている著者はいません。

著者リストをロードできませんでした。後でもう一度試してください。
