# Innioasis Y2 のテーマ

Innioasis Y2 では、従来の Y1 に比べてハードウェアの機能強化と内部ソフトウェアのアップデートが導入されています。モデルごとにテーマがどのように異なるか、また専用のファイル マネージャー アートワークを備えた完全な Y2 テーマ パッケージを見つける方法を学びます。

## Y2 テーマと Y1 テーマの違い

Y2 ソフトウェアには専用の ファイルマネージャー 標準の Y1 ストック ファームウェアには存在しないメニュー エントリ。完全な Y2 テーマには専用のファイル マネージャー アートワークが含まれているため、すべての画面が一致します。[検証済みの Y2 テーマを参照](index_ja.html?filter=y2)[Y2 テーマをアップロードする](upload_ja.html)
