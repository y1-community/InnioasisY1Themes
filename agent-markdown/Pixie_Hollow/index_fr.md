# Pixie Hollow

purplecray0ns

Puis-je être fou une seconde et dire que je n'ai toujours pas surmonté la fermeture de ce jeu il y a 14 ans, ils n'ont pas eu besoin de l'effacer d'Internet, il ne reste presque plus d'actifs du jeu original, même le curseur qu'ils ont utilisé pour l'avatar a disparu. Javascript vient d'être intégré au HTML, il ne peut donc pas fonctionner sur un script séparé, c'est pourquoi il "s'est arrêté" mais a effacé tout le jeu de la surface de la terre ??? Ils auraient pu simplement faire ce que le camp AC.pocket a fait et retirer le financement et le mode multijoueur, tout en gardant le jeu ouvert au mode solo. Non. Tout le jeu est parti. L'enfer.
