# Pixie Hollow

purplecray0ns

Kann ich für eine Sekunde verrückt sein und sagen, dass ich immer noch nicht darüber hinweggekommen bin, dass das Spiel vor 14 Jahren eingestellt wurde? Sie mussten es nicht aus dem Internet löschen. Vom Originalspiel sind kaum noch Assets übrig, sogar der Cursor, den sie für den Avatar verwendet haben, ist verschwunden. Javascript wurde gerade in HTML integriert, sodass es nicht auf einem separaten Skript ausgeführt werden konnte. Deshalb wurde es „heruntergefahren“, aber das gesamte Spiel wurde vom Erdboden vernichtet??? Sie hätten einfach das tun können, was AC.pocket Camp getan hat, und die Finanzierung und den Mehrspielermodus streichen, das Spiel aber für Einzelspieler offen halten können. Nein. Das ganze Spiel ist weg. Zum Teufel. Genießen Sie das Thema
