# Rapportera ett temaproblem

Använd det här formuläret för frågor om ett specifikt galleritema (till exempel olämpliga bilder, upphovsrätt, skadliga filer eller vilseledande texter). Om du är författaren och vill att ditt eget tema ska tas bort, välj skälet för att välja bort så kommer vi att dirigera dig till flödet för begäran om borttagning.Tack - din rapport har skickats.Om du lämnat en e-postadress bör du få en kort bekräftelse från vår formulärleverantör. Vi kan inte alltid svara individuellt.Att välja bort författare stöds. Om du inte vill att ditt tema ska listas här, välj "Jag vill inte ha mitt tema här" i rapporttyp. Vi skickar dig direkt till begäran om borttagning för verifiering. 

### Författarens borttagningsväg

Den här rapporttypen är till för att välja bort författare, så vi flyttade dig till det verifierade borttagningsflödet.
