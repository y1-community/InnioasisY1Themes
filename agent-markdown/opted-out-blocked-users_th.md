# ผู้ใช้ที่เลือกไม่ใช้และถูกบล็อก - ธีม Innioasis Y1 &amp; Y2

[Y1 & Y2 ธีม](https://themes.innioasis.app/index.html?lang=th)[บรรณาธิการ](https://y1-themes.vercel.app)[อัปโหลด](https://themes.innioasis.app/upload.html?lang=th)

# เลือกไม่ใช้และบล็อกผู้ใช้

 ผู้สร้างบางรายไม่ต้องการให้ผลงานของตนปรากฏบน Themes.innioasis.app เนื้อหาอื่นๆ ถูกแบนเนื่องจากการละเมิดหรือการส่งผลงานที่มีคุณภาพต่ำ รายการจะถูกเก็บรักษาไว้ใน [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) และ [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## ผู้เขียนที่เลือกไม่รับ

 ผู้เขียนเหล่านี้ขอไม่ให้ส่งธีมหรือเสนอให้ดาวน์โหลดบนเว็บไซต์ธีม คุณยังคงสามารถอัปโหลดแพ็คเกจที่ได้รับเครดิตสำหรับพวกเขาได้ การเก็บรักษาและการเก็บถาวร ใน [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) พื้นที่เก็บข้อมูล GitHub - ไฟล์จะยังคงอยู่ในที่เก็บถาวรของชุมชน แต่จะไม่ปรากฏในแกลเลอรีสาธารณะ ผู้สร้างที่เลือกไม่รับมักต้องการโฮสต์ผลงานของตนเอง (ร้านค้า Ko-fi, Patreon ไซต์ส่วนตัว) และมักจะสนับสนุน จ่ายในสิ่งที่คุณรู้สึก รูปแบบการบริจาคแทนที่จะแสดงรายการที่นี่ 

ขณะนี้ไม่มีผู้เขียนที่ถูกเลือกไม่รับ

## ผู้เขียนที่ถูกบล็อก

 ผู้เขียนเหล่านี้ไม่ได้รับอนุญาตในแกลเลอรีสาธารณะหรือผ่านแบบฟอร์มอัปโหลด ธีมที่ให้เครดิตจะถูกซ่อนไม่ให้ผู้เยี่ยมชมเห็น ความพยายามในการอัปโหลดอาจยังถึง GitHub ในบางกรณี แต่จะไม่มีการแสดงรายการให้ดาวน์โหลดบน Themes.innioasis.app 

ขณะนี้ไม่มีผู้เขียนที่ถูกบล็อก

ไม่สามารถโหลดรายชื่อผู้เขียนได้ ลองอีกครั้งในภายหลัง
