# 選擇退出並封鎖用戶

 有些創作者不希望他們的作品出現在 theme.innoasis.app 上。其他人則因濫用或低品質提交而被禁止。列表維護在 [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) 和 [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## 選擇退出的作者

 這些作者要求不要在主題網站上提交或提供下載主題。您仍然可以上傳記入他們的包 保存和歸檔 在 [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub 儲存庫 - 檔案保留在社群存檔中，但不會出現在公共圖庫中。選擇退出的創作者通常更喜歡託管自己的作品集（商店、Ko-fi、Patreon、個人網站），並經常鼓勵 付出你的感受 捐贈模型而不是在這裡列出。 

目前沒有作者選擇退出。

## 被封鎖的作者

 這些作者不允許出現在公共畫廊或透過上傳表單。他們的主題對訪客是隱藏的。在某些情況下，上傳嘗試可能仍會達到 GitHub，但它們不會在 theme.innioasis.app 上列出以供下載。 

目前沒有作者被封鎖。
