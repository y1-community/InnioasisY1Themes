# Themes for Innioasis Y2

The Innioasis Y2 introduces hardware enhancements and internal software updates over the classic Y1. Learn how themes differ between models and how to find complete Y2 theme packages with dedicated File Manager artwork.

## How Y2 Themes Differ from Y1 Themes

The Y2 software includes a dedicated File Manager menu entry that does not exist in standard Y1 stock firmwares. Full Y2 themes include dedicated File Manager artwork, so every screen matches.[Browse Verified Y2 Themes](index_es-419.html?filter=y2)[Upload a Y2 Theme](upload_es-419.html)
