# プライバシー - Innioasis テーマ ギャラリー

# プライバシー

最終更新日: 2026 年 11 月 8 日

テーマ.innioasis.app は、Innioasis Y1 と Y2 のコミュニティ テーマ ギャラリーです。 Ryan Specter と Innioasis コミュニティによって運営されています。 Luci Ltd がホスティングを提供します。アカウントもサインインもありません。

## デバイスに残るもの

ギャラリーでは、言語、カラーテーマ、テキストサイズ、プライバシーの選択、寄付の呼びかけを非表示にするかどうか、すでに取得した翻訳など、いくつかの設定がブラウザーに保存されます。これらはデバイス上に残ります。サイトデータをクリアすると、それらは削除されます。

## 私たちが測定するもの

Google Tag Manager と Google Analytics を使用してページビューをカウントし、どのページが失敗するか読み込みが遅いかを確認します。 Cloudflare はホスティング、セキュリティ、攻撃保護を提供します。また、ギャラリーはテーマのビュー、ダウンロード、評価の合計を独自に保持し、ランダムな訪問者 ID をブラウザーに保存するので、更新が 2 回カウントされることはありません。公開テーマの合計によって個人が特定されることはありません。

私たちはあなたの名前、電子メール、住所を尋ねることはありません。また、データを販売することもありません。

## Cookie とローカル ストレージ

このサイトでは、上記の設定と集計のためにブラウザーのストレージを使用します。 Google Analytics と Cloudflare は独自の Cookie を設定する場合があります。ブラウザでいつでも Cookie をブロックまたはクリアできます。ギャラリーは引き続き機能します。

## あなたの選択

ギャラリーへのアクセスを失うことなく、分析と投稿の評価をオフにすることができます。設定はこのデバイスに記憶され、innioasis.app の Cookie を通じてファームウェア アーカイブおよびアップデータ CE と共有されます。

## 寄付

寄付ボタンは Ko-fi、Buy Me a Coffee、PayPal、Revolut、Patreon、Boosty にリンクしています。これらのサービスは、支払いと独自のデータを処理します。このサイトがあなたのカードの詳細を閲覧することはありません。

## 他のサイトへのリンク

テーマ ページは作成者自身のサイトにリンクし、フッターは Discord、Reddit、および GitHub にリンクします。それらのサイトには独自のプライバシー ポリシーがあります。私たちは彼らが何を収集するかをコントロールしません。

## あなたの権利

EEA、英国、またはスイスにお住まいの場合は、どのような個人データが自分に関係しているのかを尋ねたり、コピーを要求したり、削除したり、処理に異議を唱えたりすることができます。カリフォルニア州の居住者は、個人情報の把握または削除を要求したり、販売をオプトアウトしたりできます。販売しておりません。

ギャラリーにはアカウントがないため、訪問者のブラウザに保存されているランダムな ID がなければ、訪問者にリクエストを接続できない場合があります。からお問い合わせいただけます。 [リポジトリの問題ページ](https://github.com/y1-community/InnioasisY1Themes/issues) または [r/innioasis](https://reddit.com/r/innioasis).

## 子供たち

ギャラリーは 13 歳未満の子供を対象としていないため、意図的に子供から個人情報を収集することはありません。

## 変更点

このポリシーが変更されると、上部の日付も変更されます。マテリアルの変更はギャラリーのホームページに記載されます。

このページの英語のテキストが正式版です。ポリシーをあなたの言語で読めるように、翻訳されたコピーが提供されます。翻訳と英語のテキストが一致しない場合は、英語のテキストが適用されます。
