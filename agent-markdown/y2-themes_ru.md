# Темы для Innioasis Y2

В Innioasis Y2 представлены усовершенствования аппаратного обеспечения и внутренние обновления программного обеспечения по сравнению с классическим Y1. Узнайте, чем отличаются темы для разных моделей и как найти полные пакеты тем Y2 со специальными изображениями файлового менеджера.

## Чем Y2 темы отличаются от Y1 тем

Программное обеспечение Y2 включает в себя специальный Файловый менеджер Пункт меню, которого нет в стандартных Y1 стоковых прошивках. Полные темы Y2 включают в себя специальную иллюстрацию Файлового менеджера, поэтому все экраны совпадают.[Просмотреть проверенные Y2 темы](index_ru.html?filter=y2)[Загрузите тему Y2](upload_ru.html)
