# Menyisih dan memblokir pengguna

 Beberapa pembuat konten tidak ingin karyanya tercantum di Themes.innioasis.app. Lainnya dilarang karena penyalahgunaan atau kiriman berkualitas rendah. Daftar disimpan di [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) dan [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## Penulis yang tidak ikut serta

 Para penulis ini telah meminta agar tema tidak dikirimkan atau ditawarkan untuk diunduh di Situs Tema. Anda masih dapat mengunggah paket yang dikreditkan kepada mereka pelestarian dan pengarsipan di [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub repositori - file tetap berada di arsip komunitas, tetapi tidak akan muncul di galeri publik. Pembuat konten yang tidak ikut serta biasanya lebih memilih untuk menghosting portofolio mereka sendiri (toko, Ko-fi, Patreon, situs pribadi) dan sering kali mendorong a Bayar Apa yang Anda Rasakan model donasi daripada mendaftar di sini. 

Tidak ada penulis yang saat ini memilih untuk tidak ikut serta.

## Penulis yang diblokir

 Penulis ini tidak diperbolehkan berada di galeri publik atau melalui formulir unggah. Tema yang dikreditkan kepada mereka disembunyikan dari pengunjung. Upaya pengunggahan mungkin masih mencapai GitHub dalam beberapa kasus, namun upaya tersebut tidak akan terdaftar untuk diunduh di Themes.innioasis.app. 

Tidak ada penulis yang diblokir saat ini.

Tidak dapat memuat daftar penulis. Coba lagi nanti.
