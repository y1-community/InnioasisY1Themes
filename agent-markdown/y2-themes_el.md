# Θέματα για Innioasis Y2

Το Innioasis Y2 εισάγει βελτιώσεις υλικού και εσωτερικές ενημερώσεις λογισμικού σε σχέση με το κλασικό Y1. Μάθετε πώς διαφέρουν τα θέματα μεταξύ των μοντέλων και πώς μπορείτε να βρείτε πλήρη Y2 πακέτα θεμάτων με αποκλειστικό έργο τέχνης Διαχείριση αρχείων.

## Πώς διαφέρουν τα Y2 Θέματα από τα Y1 Θέματα

Το λογισμικό Y2 περιλαμβάνει ένα αποκλειστικό Διαχείριση αρχείων καταχώρηση μενού που δεν υπάρχει σε τυπικά υλικολογισμικά μετοχών Y1. Τα πλήρη Y2 θέματα περιλαμβάνουν αποκλειστικό καλλιτεχνικό έργο του File Manager, έτσι ώστε κάθε οθόνη να ταιριάζει.[Περιήγηση σε επαληθευμένα Y2 θέματα](index_el.html?filter=y2)[Ανεβάστε ένα Y2 Θέμα](upload_el.html)
