# Original software til Innioasis og Timmkoo spillere

Original software er det officielle fabriksoperativsystem, der leveres på Innioasis og Timmkoo bærbare afspillere. Det giver stensikker hardwarestabilitet, fuld støtte til brugerdefinerede skins fra [Temagalleri](https://themes.innioasis.app/?lang=da), FM-radio, Bluetooth-lydstreaming, lagring af lydbogsfremskridt og sikker fabriksgendannelse via Innioasis Updater CE.[Gennemse softwaredownloads](firmware.html)[Hent Updater CE](guide.html#platform)[Gennemse temagalleriet](https://themes.innioasis.app/?lang=da)

## Hvorfor bruge eller gendanne original software?

### Fuld temagalleri support

Original software på Y1 og Y2 fungerer direkte med brugerdefinerede skins fra [Temagalleri](https://themes.innioasis.app/?lang=da). Skift ikoner, baggrundsbaggrunde, afspillerskiver og skrifttyper uden at ændre kernesystempartitioner.

### Alt fungerer ud af boksen

Fuld understøttelse af Bluetooth-hovedtelefoner og bilstereo, fysisk klikhjulsnavigation, hardware FM-radiotuning, bogmærke til lydbøger, e-bøger og videoafspilning uden manuel konfiguration.

### Sikker gendannelse & Unbrick Baseline

Hvis du nogensinde ønsker at vende tilbage fra et brugerdefineret firmwareeksperiment eller gendanne en afspiller, der ikke vil starte, gendanner Updater CE Original Software i et enkelt guidet trin.
