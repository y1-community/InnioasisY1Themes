# تم برای Innioasis Y2

Innioasis Y2 پیشرفت‌های سخت‌افزاری و به‌روزرسانی‌های نرم‌افزار داخلی را نسبت به Y1 کلاسیک معرفی می‌کند. بیاموزید که چگونه تم ها بین مدل ها تفاوت دارند و چگونه می توانید بسته های تم کامل Y2 را با آثار هنری اختصاصی File Manager پیدا کنید.

## چگونه Y2 تم ها با Y1 تم ها تفاوت دارند

نرم افزار Y2 شامل یک نرم افزار اختصاصی است مدیر فایل ورودی منو که در سیستم عامل های سهام استاندارد Y1 وجود ندارد. تم‌های کامل Y2 شامل آثار هنری مدیریت فایل اختصاصی است، بنابراین هر صفحه‌ای مطابقت دارد.[تم های تأیید شده Y2 را مرور کنید](index_fa.html?filter=y2)[یک تم Y2 بارگذاری کنید](upload_fa.html)
