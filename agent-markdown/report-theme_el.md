# Αναφέρετε ένα θέμα θέματος

Χρησιμοποιήστε αυτήν τη φόρμα για ανησυχίες σχετικά με ένα συγκεκριμένο θέμα γκαλερί (για παράδειγμα ακατάλληλες εικόνες, πνευματικά δικαιώματα, επιβλαβή αρχεία ή παραπλανητικές πιστώσεις). Εάν είστε ο συγγραφέας και θέλετε να αφαιρεθεί το δικό σας θέμα, επιλέξτε τον λόγο εξαίρεσης και θα σας δρομολογήσουμε στη ροή αιτημάτων κατάργησης.Ευχαριστώ - η αναφορά σας στάλθηκε.Εάν έχετε αφήσει μια διεύθυνση email, θα πρέπει να λάβετε μια σύντομη επιβεβαίωση από τον πάροχο της φόρμας μας. Δεν μπορούμε να απαντάμε πάντα μεμονωμένα.Υποστηρίζεται η εξαίρεση του συγγραφέα. Εάν δεν θέλετε το θέμα σας να αναφέρεται εδώ, επιλέξτε "Δεν θέλω το θέμα μου εδώ" στον τύπο αναφοράς. Θα σας στείλουμε απευθείας στο αίτημα κατάργησης για επαλήθευση. 

### Διαδρομή αφαίρεσης συγγραφέα

Αυτός ο τύπος αναφοράς προορίζεται για εξαίρεση συντάκτη, επομένως σας μεταφέραμε στην επαληθευμένη ροή κατάργησης.

[Ανοίξτε το αίτημα αφαίρεσης](https://themes.innioasis.app/upload.html?mode=remove&lang=el)[Μείνετε στη φόρμα αναφοράς](https://themes.innioasis.app/report-theme.html?lang=el)Το email σας (απαιτείται)

Μπορούμε λοιπόν να συνεχίσουμε αν χρειαζόμαστε περισσότερες λεπτομέρειες. Δεν δημοσιεύουμε τη διεύθυνσή σας.Φάκελος θέματος (διαδρομή αποθετηρίου)
