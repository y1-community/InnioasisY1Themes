# รายงานปัญหาเกี่ยวกับธีม

ใช้แบบฟอร์มนี้สำหรับข้อกังวลเกี่ยวกับธีมแกลเลอรีเฉพาะ (เช่น ภาพที่ไม่เหมาะสม ลิขสิทธิ์ ไฟล์ที่เป็นอันตราย หรือเครดิตที่ทำให้เข้าใจผิด) หากคุณเป็นผู้เขียนและต้องการให้ลบธีมของคุณเอง ให้เลือกเหตุผลในการไม่เข้าร่วม แล้วเราจะนำคุณไปยังขั้นตอนคำขอลบออกขอบคุณ รายงานของคุณถูกส่งไปแล้วหากคุณทิ้งที่อยู่อีเมลไว้ คุณควรได้รับการยืนยันสั้นๆ จากผู้ให้บริการแบบฟอร์มของเรา เราไม่สามารถตอบกลับเป็นรายบุคคลได้ตลอดเวลารองรับการเลือกไม่รับผู้เขียน หากคุณไม่ต้องการให้ธีมของคุณแสดงอยู่ที่นี่ ให้เลือก “ฉันไม่ต้องการธีมของฉันที่นี่” ในรูปแบบรายงาน เราจะส่งคุณโดยตรงไปยังคำขอลบเพื่อตรวจสอบ 

### เส้นทางการลบผู้เขียน

รายงานประเภทนี้มีไว้สำหรับผู้เขียนที่เลือกที่จะไม่รับ ดังนั้นเราจึงย้ายคุณไปยังขั้นตอนการลบที่ได้รับการยืนยัน

[เปิดคำขอลบ](https://themes.innioasis.app/upload.html?mode=remove&lang=th)[อยู่ในแบบฟอร์มรายงาน](https://themes.innioasis.app/report-theme.html?lang=th)อีเมลของคุณ (ที่จำเป็น)

ดังนั้นเราจึงสามารถติดตามผลหากต้องการรายละเอียดเพิ่มเติม เราไม่เผยแพร่ที่อยู่ของคุณโฟลเดอร์ธีม (เส้นทางพื้นที่เก็บข้อมูล)

ชื่อธีม (ดังแสดงในแกลเลอรี)ผู้แต่ง/วงเงินเครดิตนี่เป็นปัญหาประเภทใด?เลือกหนึ่ง…ฉันไม่ต้องการธีมของฉันที่นี่ (ผู้เขียนเลือกไม่รับ)ข้อกังวลด้านเนื้อหาที่ผิดกฎหมาย/เป็นอันตรายเนื้อหาที่ไม่เหมาะสมหรือไม่เหมาะสมข้อกังวลด้านลิขสิทธิ์หรือเครื่องหมายการค้า/ทรัพย์สินทางปัญญามัลแวร์ ฟิชชิ่ง หรือไฟล์ที่น่าสงสัยการแอบอ้างบุคคลอื่น การคุกคาม หรือความเกลียดชังสแปม การหลอกลวง หรือรายการที่ทำให้เข้าใจผิดอื่นๆ (อธิบายด้านล่าง)กรุณาอธิบาย

ขั้นต่ำ 20 ตัวอักษร เฉพาะเจาะจง - ช่วยให้ผู้ดูแลดำเนินการได้เร็วขึ้นส่งรายงาน
