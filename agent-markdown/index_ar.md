# المواضيع

معرض للموضوعات الخاصة بـ Innioasis Y1 و Y2، من إعداد المجتمع. قم بمعاينة المظهر قبل تثبيته، أو قم بتحميل القالب الذي قمت بإنشائه.[ تحميل الموضوع](upload_ar.html)[ Rockbox المواضيع](https://innioasis.app/rockbox-y1-themes.html?utm_source=themes.innioasis.app&utm_medium=referral&utm_campaign=rockbox_themes&ref=themes_gallery&what=theme&resolution=360p)التثبيت المباشرقم بالتثبيت مباشرة على Y1 أو Y2 - اختر مجلد سمات المشغل، بدون تنزيلات مضغوطة.اختر مجلد المواضيع تم تحديد المجلدتحديث الكل على Y1  إظهار السمات الموجودة بالفعل على Y1 فقط  مصدر جميع المواضيعحزم المعرضروابط خارجية مؤلف جميع المؤلفينواضح نوع الاسم (أ-ي)الاسم (ي-أ)المؤلف (من الألف إلى الياء)معظم المشاهداتأقل المشاهداتمعظم التنزيلاتأقل التنزيلاتأعلى تصنيفأدنى تصنيف لكل صفحة 122448 الذهب فقط لا توجد سمات تتطابق مع عوامل التصفية الحالية.
