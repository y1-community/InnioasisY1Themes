# ביטלו את הסכמתם וחסמו משתמשים

 חלק מהיוצרים לא רוצים שהעבודות שלהם יופיעו ב-themes.innioasis.app. אחרים נאסרים בגלל שימוש לרעה או הגשות באיכות נמוכה. רשימות נשמרות ב [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) ו [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## מחברים מבוטל

 מחברים אלה ביקשו שלא להגיש או להציע ערכות נושא להורדה באתר הנושאים. אתה עדיין יכול להעלות חבילות שזוכות להם עבור שימור וארכיון ב- [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) מאגר GitHub - קבצים נשארים בארכיון הקהילה, אך הם לא יופיעו בגלריה הציבורית. יוצרים שהצטרפו בדרך כלל מעדיפים לארח תיק עבודות משלהם (חנות, Ko-fi, Patreon, אתר אישי) ולעתים קרובות מעודדים שלם מה שאתה מרגיש מודל תרומות במקום רישום כאן. 

כרגע אין מחברים שנדחו.

## מחברים חסומים

 מחברים אלה אינם מורשים להיכנס לגלריה הציבורית או דרך טופס ההעלאה. נושאים הנזקפים לזכותם מוסתרים מהמבקרים. ניסיונות העלאה עשויים עדיין להגיע ל-GitHub במקרים מסוימים, אך הם לא יופיעו להורדה ב-themes.innioasis.app. 

אין מחברים חסומים כרגע.

לא ניתן לטעון רשימות מחברים. נסה שוב מאוחר יותר.
