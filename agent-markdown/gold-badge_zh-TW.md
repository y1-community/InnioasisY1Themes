## 我們如何決定

 金牌是社區品質標誌，而不是保固。我們會自動檢查每個主題，以便徽章與包中的內容相符。如果未來的 Y1 或 Y2 更新破壞了某些內容，徽章可能會脫落，直到修復為止。 技術細節（針對主題製作者）

當主題通過我們的藝術作品相容性檢查時即可獲得金牌（與畫廊徽章相同）：
  - `config.json` 列出 Rockbox 啟動器開關、電子書閱讀器、計算機和日曆的路徑。
  - 每個連結的文件都存在並且是真實的藝術品 - 不是 `transparent.png` 或 `backfill.png` 佔位符 `launcher.png`, `calendar.png`, `ebook.png`, 或 `calculator.png`.
  - 作者可以設定 `gallery.compatibilityMedal` 到 `gold` 或 `none` 強制開啟或關閉徽章。

 當您開啟此頁面或圖庫時，會批次檢查主題。全新上傳可能需要一段時間才會出現黃金級。 

 在安裝任何主題之前，請務必備份您的 Y1 或 Y2。
