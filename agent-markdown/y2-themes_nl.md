# Thema's voor Innioasis Y2

De Innioasis Y2 introduceert hardwareverbeteringen en interne software-updates ten opzichte van de klassieke Y1. Ontdek hoe thema's verschillen tussen modellen en hoe u complete Y2 themapakketten kunt vinden met speciale File Manager-illustraties.

## Hoe Y2 thema's verschillen van Y1 thema's

De Y2-software bevat een speciaal Bestandsbeheer menu-item dat niet bestaat in standaard Y1 voorraadfirmware. De volledige Y2-thema's bevatten speciale File Manager-illustraties, zodat elk scherm overeenkomt.[Blader door geverifieerde Y2-thema's](index_nl.html?filter=y2)[Upload een Y2-thema](upload_nl.html)
