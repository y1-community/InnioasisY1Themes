# Teme pentru Innioasis Y2

Innioasis Y2 introduce îmbunătățiri hardware și actualizări interne de software față de clasicul Y1. Aflați cum diferă temele între modele și cum să găsiți pachete de teme complete Y2 cu grafică dedicată File Manager.

## Cum diferă Y2 teme de Y1 teme

Software-ul Y2 include un software dedicat Manager de fișiere intrare de meniu care nu există în firmware-urile standard de stoc Y1. Temele complete Y2 includ ilustrații dedicate Manager de fișiere, astfel încât fiecare ecran se potrivește.[Răsfoiți Y2 teme verificate](index_ro.html?filter=y2)[Încărcați o temă Y2.](upload_ro.html)
