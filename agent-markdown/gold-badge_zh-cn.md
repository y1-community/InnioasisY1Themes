## 我们如何决定

 金牌是社区质量标志，而不是保修。我们会自动检查每个主题，以便徽章与包中的内容相匹配。如果未来的 Y1 或 Y2 更新破坏了某些内容，徽章可能会脱落，直到修复为止。 技术细节（针对主题制作者）

当主题通过我们的艺术作品兼容性检查时即可获得金牌（与画廊徽章相同）：
  - `config.json` 列出 Rockbox 启动器开关、电子书阅读器、计算器和日历的路径。
  - 每个链接的文件都存在并且是真实的艺术品 - 不是 `transparent.png` 或 `backfill.png` 占位符 `launcher.png`, `calendar.png`, `ebook.png`, 或 `calculator.png`.
  - 作者可以设置 `gallery.compatibilityMedal` 至 `gold` 或 `none` 强制打开或关闭徽章。

 当您打开此页面或图库时，会批量检查主题。全新上传可能需要一段时间才会出现黄金级。 

 在安装任何主题之前，请务必备份您的 Y1 或 Y2。
