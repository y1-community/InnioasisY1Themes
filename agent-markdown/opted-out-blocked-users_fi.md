# Poistettu ja estetty käyttäjät

 Jotkut sisällöntuottajat eivät halua töitään olevan themes.innioasis.app -sivustossa. Muut ovat kiellettyjä väärinkäytösten tai heikkolaatuisten lähetysten vuoksi. Listoja ylläpidetään [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) ja [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## Poistuneet kirjoittajat

 Nämä kirjoittajat ovat pyytäneet, että he eivät saa lähettää tai tarjota ladattavia teemoja Teemasivustolla. Voit silti ladata heille hyvitettyjä paketteja säilyttäminen ja arkistointi in [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub arkisto - tiedostot pysyvät yhteisön arkistossa, mutta ne eivät näy julkisessa galleriassa. Opt-out-sisällöntuottajat haluavat yleensä isännöidä omaa portfoliotaan (kauppa, Ko-fi, Patreon, henkilökohtainen sivusto) ja kannustavat usein Maksa mitä tunnet lahjoitusten mallin sijaan täällä. 

Yksikään kirjoittaja ei ole tällä hetkellä pois käytöstä.

## Estetyt kirjoittajat

 Nämä kirjoittajat eivät ole sallittuja julkisessa galleriassa tai latauslomakkeen kautta. Niille annetut teemat on piilotettu vierailijoilta. Latausyritykset voivat silti saavuttaa GitHub joissakin tapauksissa, mutta niitä ei näytetä ladattavissa osoitteessa themes.innioasis.app. 

Yhtään kirjoittajaa ei ole tällä hetkellä estetty.

Tekijäluetteloita ei voitu ladata. Yritä myöhemmin uudelleen.
