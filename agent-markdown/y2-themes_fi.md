# Teemat: Innioasis Y2

Innioasis Y2 esittelee laitteiston parannuksia ja sisäisiä ohjelmistopäivityksiä klassiseen Y1 verrattuna. Opi kuinka teemat eroavat mallien välillä ja kuinka löydät täydelliset Y2 teemapaketit erillisillä tiedostonhallinnan kuvilla.

## Kuinka Y2-teemat eroavat Y1-teemoista

Y2-ohjelmisto sisältää erillisen Tiedostonhallinta valikkokohta, jota ei ole Y1-standardin laiteohjelmistoissa. Täydelliset Y2-teemat sisältävät erityisiä File Manager -kuvia, joten jokainen näyttö sopii yhteen.[Selaa vahvistettuja Y2 teemoja](index_fi.html?filter=y2)[Lataa Y2 teema](upload_fi.html)
