# Innioasis Y2에 대한 테마

Innioasis Y2은 클래식 Y1에 비해 하드웨어 개선 사항과 내부 소프트웨어 업데이트를 도입합니다. 모델 간 테마의 차이점과 전용 파일 관리자 아트워크가 포함된 전체 Y2 테마 패키지를 찾는 방법에 대해 알아보세요.

## Y2 테마와 Y1 테마의 차이점

Y2 소프트웨어에는 전용 파일 관리자 표준 Y1 재고 펌웨어에는 존재하지 않는 메뉴 항목입니다. 전체 Y2 테마에는 전용 파일 관리자 아트워크가 포함되어 있으므로 모든 화면이 일치합니다.[검증된 Y2 테마 찾아보기](index_ko.html?filter=y2)[Y2 테마 업로드](upload_ko.html)
