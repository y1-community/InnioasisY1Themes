# Motivy pro Innioasis Y2

Innioasis Y2 zavádí hardwarová vylepšení a interní aktualizace softwaru oproti klasickému Y1. Zjistěte, jak se liší motivy mezi modely a jak najít kompletní Y2 balíčky motivů s vyhrazenou kresbou Správce souborů.

## Jak se Y2 témata liší od Y1 témat

Software Y2 obsahuje vyhrazený Správce souborů položka nabídky, která neexistuje ve standardních Y1 firmwarech. Úplná Y2 témata zahrnují vyhrazenou grafiku Správce souborů, takže každá obrazovka odpovídá.[Procházet ověřené Y2 motivy](index_cs.html?filter=y2)[Nahrajte motiv Y2](upload_cs.html)
