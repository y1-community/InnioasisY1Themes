# Оригинальное программное обеспечение для проигрывателей Innioasis и Timmkoo

Заводское ПО — официальная заводская операционная система, поставляемая на портативных плеерах Innioasis и Timmkoo. Он обеспечивает надежную аппаратную стабильность, полную поддержку пользовательских скинов из [Галерея тем](https://themes.innioasis.app/?lang=ru), FM-радио, потоковое аудио по Bluetooth, сохранение прогресса аудиокниги и безопасное восстановление заводских настроек с помощью Innioasis Updater CE.[Просмотрите загрузки программного обеспечения](firmware.html)[Скачать Updater CE](guide.html#platform)[Просмотреть галерею тем](https://themes.innioasis.app/?lang=ru)

## Зачем использовать или восстанавливать оригинальное программное обеспечение?

### Полная поддержка галереи тем

Оригинальное программное обеспечение на Y1 и Y2 работает напрямую с пользовательскими скинами из [Галерея тем](https://themes.innioasis.app/?lang=ru). Меняйте значки, фоновые обои, диски проигрывателя и шрифты, не изменяя основные системные разделы.

### Все работает из коробки

Полная поддержка наушников Bluetooth и автомобильной аудиосистемы, физической навигации с помощью колесика управления, аппаратной настройки FM-радио, создания закладок аудиокниг, электронных книг и воспроизведения видео без необходимости ручной настройки.

### Безопасное восстановление и разблокировка базового уровня

Если вы когда-нибудь захотите отказаться от эксперимента с пользовательской прошивкой или восстановить плеер, который не загружается, Updater CE восстановит исходное программное обеспечение за один пошаговый шаг.
