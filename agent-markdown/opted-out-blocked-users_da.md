# Fravalgte og blokerede brugere

 Nogle skabere ønsker ikke, at deres arbejde er opført på themes.innioasis.app. Andre er forbudt på grund af misbrug eller indlæg af lav kvalitet. Lister vedligeholdes i [opt_out.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/opt_out.json) og [block.json](https://github.com/y1-community/InnioasisY1Themes/blob/main/block.json). 

## Fravalgte forfattere

 Disse forfattere har bedt om ikke at få temaer indsendt eller tilbudt til download på temasiden. Du kan stadig uploade pakker krediteret til dem for bevaring og arkivering i [y1-community/InnioasisY1Themes](https://github.com/y1-community/InnioasisY1Themes) GitHub repository - filer forbliver i fællesskabsarkivet, men de vises ikke i det offentlige galleri. Fravalgte skabere foretrækker normalt at være vært for deres egen portefølje (butik, Ko-fi, Patreon, personlig side) og opfordrer ofte til en Betal hvad du føler donationsmodel i stedet for at liste her. 

Ingen forfattere er i øjeblikket fravalgt.

## Blokerede forfattere

 Disse forfattere er ikke tilladt på det offentlige galleri eller via uploadformularen. Temaer, der krediteres dem, er skjult for besøgende. Uploadforsøg kan stadig nå GitHub i nogle tilfælde, men de vil ikke blive vist til download på themes.innioasis.app. 

Ingen forfattere er blokeret i øjeblikket.

Kunne ikke indlæse forfatterlister. Prøv igen senere.
