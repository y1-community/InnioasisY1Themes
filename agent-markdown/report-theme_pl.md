# Zgłoś problem z motywem

Użyj tego formularza, jeśli masz wątpliwości dotyczące konkretnego tematu galerii (na przykład nieodpowiednie zdjęcia, prawa autorskie, szkodliwe pliki lub wprowadzające w błąd napisy). Jeśli jesteś autorem i chcesz, aby Twój motyw został usunięty, wybierz powód rezygnacji, a my przekierujemy Cię do procedury żądania usunięcia.Dziękujemy - Twoje zgłoszenie zostało wysłane.Jeśli zostawiłeś adres e-mail, powinieneś otrzymać krótkie potwierdzenie od naszego dostawcy formularza. Nie zawsze możemy odpowiedzieć indywidualnie.Obsługiwana jest rezygnacja autora. Jeśli nie chcesz, aby Twój motyw był tutaj wyświetlany, wybierz „Nie chcę tutaj mojego tematu” w typie raportu. Prześlemy Cię bezpośrednio do prośby o usunięcie w celu weryfikacji. 

### Droga usunięcia autora

Ten typ raportu dotyczy rezygnacji autora, dlatego przenieśliśmy Cię do zweryfikowanego procesu usuwania.
