Innioasis Y2 themes

The Y2 reads the same theme files as the Y1 when it is running the Original Software, Better-Y, Koensayr or Solar.

Y2 themes and Y2 skins

People search for both. A skin and a theme are the same download here. Open the gallery, preview a theme, and install it on the Y2. The player is the compact model with buttons and a touchscreen.

Y2 Rockbox themes

Rockbox on the Y2 does not use these files. Those themes come with the Rockbox install. See Rockbox ערכות נושא and the Y2 firmware archive for the system itself.
