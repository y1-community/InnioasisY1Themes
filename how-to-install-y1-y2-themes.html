How to install a theme on the Innioasis Y1 and Y2

Every theme in this gallery installs the same way, whichever software the player runs. Pick the method that matches what you have: Updater CE on a computer, a USB cable, or a Solar player with Wi-Fi.

Before you start

  • Know which software the player runs: Original Software, Better-Y, Koensayr, Solar or Rockbox.
  • For Updater CE or a USB copy, you need a computer and a data-capable USB cable.
  • For Rockbox, use the Rockbox collection instead; its themes install through Rockbox.

Method 1: install with Updater CE

  1. Open the Themes Gallery, choose a theme and download it.
  2. Open Updater CE on Windows, macOS or Linux.
  3. Connect the player over USB when Updater CE asks for it.
  4. Use its theme option to add the downloaded theme to the player.
  5. Disconnect the player and select the theme in the player's theme picker.

Updater CE is the option that avoids hunting for the correct folder, and it also handles firmware updates and player checks.

Method 2: copy the theme over USB

  1. Download the theme and unzip it if your download is an archive.
  2. Connect the player. It appears as a removable drive on Windows, macOS and Linux.
  3. Copy the theme folder into the player's theme folder, keeping the folder structure the theme came with.
  4. Eject the player safely, disconnect it and select the theme on the device.

Copy the folder as it was packaged. Renaming its internal files or flattening its subfolders is the usual reason a copied theme does not appear in the picker.

Method 3: download on a Solar player

  1. Connect the player to Wi-Fi.
  2. Open Solar's theme browser.
  3. Preview a theme and download it. Solar installs it on the player without a computer.
  4. Select the theme in the player's theme picker.

Solar's Wi-Fi download is the fastest route when you do not have a computer nearby. The same themes are in this gallery, so you can also download on a computer and copy them across later.

After installing

Open the player's theme picker and select the new theme. If the theme has colour variants, they appear as separate choices. Your music, settings and firmware stay as they were; switching back to the previous theme is just another selection in the same picker.

Troubleshooting

The theme does not appear in the pickerThe folder is in the player's theme folder and keeps the structure from the download. Re-select or restart the player.
Colours or icons look wrongThe theme may be for a different screen size. Check the theme page's device notes and re-download the current file.
The player is not detected over USBUse a data cable, not a charge-only one, and try another port. On Linux, check that the player mounted.

Solar's theme browser cannot downloadCheck the Wi-Fi connection, then retry. A computer download and USB copy is the fallback.

Installation questions

Where do themes go on a Y1 or Y2?

The player's theme folder. Updater CE places the file there for you; a manual copy uses the same folder the theme picker reads.

Do I need Updater CE?

No. USB copy and Solar's Wi-Fi download both work without it. Updater CE is simply the least error-prone option on a computer.

Does a theme erase my music?

No. Themes are separate files and do not touch the music library or firmware.

Can I install a theme on a player running Rockbox?

Only a Rockbox theme. The shared gallery themes are for Better-Y, Koensayr, Solar and the Original Software.
