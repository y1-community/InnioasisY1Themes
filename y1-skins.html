Innioasis Y1 skins

On the Y1, a skin is a theme. It is the set of pictures and fonts that replace the ones that shipped with the player.

Which skins work

Skins from the gallery work on the Original Software, Better-Y, Koensayr and Solar. Searchers also call them Y1 themes. Rockbox skins are a different format. Those are in the Rockbox theme pack.

Install a Y1 skin

Download the theme and copy its folder into the themes folder on the Y1, or use Direct Install via USB from the theme page. Install steps are the same for a skin and a theme.
