Better-Y themes for the Innioasis Y1 and Y2

This gallery hosts the Better-Y themes people use on the Innioasis Y1 and Y2. Every theme here is built for the shared Innioasis theme format, so the same download also works when the player runs Koensayr, Solar or the Original Software.

What a Better-Y theme is

Better-Y is a community software build for the Innioasis Y1 and Y2. It changes how the player behaves. A theme is separate from that: it changes the colours, icons, backgrounds and layout you see while you browse your music. Installing one does not replace Better-Y, downgrade it or touch your files.

Because the theme format is shared, there is no such thing as a theme that only exists for Better-Y. The gallery keeps one collection and the Better-Y name is simply how many people find it.

Better-Y themes on Koensayr, Solar and the Original Software

All four software options read the same theme files. If you find a theme on this page and later switch from Better-Y to Koensayr, Solar or the stock Original Software, that theme still works. You do not need to download a different copy or convert anything.

Rockbox is the exception. Rockbox uses its own theme format and cannot load the themes on this page. If your player runs Rockbox, use the Rockbox theme collection instead.

Better-Y themes for the Innioasis Y1

The Y1 is where most of the gallery started, and it has the largest choice of themes. Open any theme page to preview it at the player's screen size, look at the colour variants, and download the version you want. Themes are community submissions, so the page also credits the person who made it.

Better-Y themes for the Innioasis Y2

The Y2 uses the same collection. A theme you like on the Y1 is the same download on the Y2, which is why you will see the same theme pages listed for both players. If a theme has device-specific artwork, the theme page says so before you download.

How to install a Better-Y theme

  1. Open the themes gallery and preview a theme.
  2. Download the theme file from its page.
  3. Add it to the player with Updater CE, or copy it to the player's themes folder over USB.
  4. On Solar you can also browse and download themes over Wi-Fi directly on the player, without a computer.

Step-by-step instructions for every method are on the theme installation guide.

Better-Y theme questions

Do Better-Y themes work with Koensayr, Solar and the Original Software?

Yes. All four use the same theme format. A theme downloaded from this gallery works on any of them, and switching software does not break the theme.

Do Better-Y themes for the Y1 work on the Y2?

Yes. The gallery keeps one collection for both players, so the Y1 and Y2 entries point at the same themes.

Does installing a theme change my firmware?

No. Themes only change the interface. Your Better-Y version, settings and music library are untouched.

Where do I get Better-Y itself?

The Innioasis firmware archive lists the community builds and stock software, including Better-Y, with installation notes.
