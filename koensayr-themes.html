Koensayr themes for the Innioasis Y1 and Y2

This gallery hosts the themes Koensayr users install on the Innioasis Y1 and Y2. Koensayr shares its theme format with Better-Y, Solar and the Original Software, so every theme here also works if you run one of those instead.

Koensayr themes are not a separate collection

People search for Koensayr themes as if Koensayr needed its own set of files. It does not. The player's software decides how the device works; the theme decides what it looks like. Both the Y1 and Y2 read the same theme format whichever of the four software builds is installed, so a theme made for the gallery is a Koensayr theme, a Better-Y theme, a Solar theme and an Original Software theme at the same time.

What you can change with a Koensayr theme

Themes change the colours, icons, backgrounds, fonts and layout of the interface. They do not change the software version, the player's settings or your music. If you later update or reinstall Koensayr, the theme remains a separate file and can be selected again.

Koensayr on the Innioasis Y1

The Y1 has the widest choice in the gallery. Each theme page shows a preview at the player's screen size and lists any colour variants, so you can see the result before downloading. Themes are submitted by the community and the page credits the author.

Koensayr on the Innioasis Y2

The Y2 uses the same theme collection. A theme that looks right on your Y1 is the same download on the Y2, and the gallery does not split the two players into separate catalogues.

Running Rockbox? Rockbox themes are their own format and are not interchangeable with Koensayr, Better-Y, Solar or Original Software themes. Use the Rockbox collection instead.

How to install a Koensayr theme

  1. Preview a theme in the gallery and download it.
  2. Install it with Updater CE, or copy the theme into the player's theme folder over USB.
  3. Pick the theme on the player. If you use Solar, you can also download themes over Wi-Fi on the device itself.

The installation guide covers each method step by step.

Koensayr theme questions

Are Koensayr themes different from other Y1 and Y2 themes?

No. Koensayr reads the same files as Better-Y, Solar and the Original Software, so there is one gallery collection rather than a Koensayr-only set.

Can I keep a Koensayr theme if I switch software?

Yes. The theme keeps working when you move between Koensayr, Better-Y, Solar and the Original Software.

Do Rockbox themes work on Koensayr?

No. Rockbox uses a different theme format and has its own collection.

Where do I download Koensayr itself?

The Innioasis firmware archive lists Koensayr alongside the stock software and the other community builds.
