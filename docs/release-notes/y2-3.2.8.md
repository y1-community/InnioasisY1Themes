# Innioasis Y2 Firmware 3.2.8

*Published 27 November 2026 · Android 4.4.4 · Y2 hardware — latest stock build*

The current Y2 firmware, and the one to install. It fixes the two cosmetic bugs that have been reported most often since launch, and keeps every feature from 3.2.0 onward.

## What's in this update?

- **The player is called Y2 again.** The launcher name had accidentally been left as `收音机` — Chinese for "radio" — since the very first Y2 build. It now reports **Y2** wherever the system asks for the app name, so launchers, settings screens and connected tools show the right thing.
- **The Unseen theme no longer draws a stray File Manager icon.** With native icon fallback enabled, Unseen was silently pulling in the system File Manager icon into the home screen. The theme now explicitly blanks that slot, so its carefully hidden layout stays hidden.
- **General performance, bug and stability fixes** across the player.
- **All five bundled themes are consistent.** HoloBubble, Unseen, Melody Munchkin, HoloFacet and Classic each ship a complete settings set and are identical whether you load them from the firmware or copy them out to `/Themes/` on USB storage.

## For theme creators

- The theme format is the same as 3.2.0, so no theme needs rewriting.
- The one thing to check: if you have a theme that relies on native icon fallback for the File Manager slot but *wants* it empty, declare the slot explicitly as transparent. That is exactly the fix Unseen received in this release, and it is the pattern to copy.
- Themes from 3.1.7 and later all load unchanged; Y1 themes still will not install, because the two formats differ.

## Good to know

- The **ROM version is 3.2.8** while the launcher reports **3.2.9**; both are correct for this release.
- This is the newest Y2 stock firmware in the archive. Y1 owners should look at Y1 3.1.2 instead — the two firmwares are not interchangeable.
