# Innioasis Y2 Firmware 3.2.1

*Build date 14 August 2026 · Published 13 September 2026 · Android 4.4.4 · Y2 hardware*

A maintenance release published alongside 3.2.0. Nothing new to learn — it is the same Y2 you already know, with the rough edges smoothed.

## What's in this update?

- **Performance and stability improvements** throughout the player, with no changes to menus, features or settings.
- **Feature parity with 3.2.0.** All of it is here: FM radio, categorized Settings, speaker toggle, headphone gain, click wheel sensitivity and volume, album art style, video scan modes and continue-playing prompts.
- **No theme changes.** Bundled themes, the settings slot count and the theme format are identical to 3.2.0.

## Good to know

- If you are already on 3.2.0, this update changes nothing you can see or configure.
- Later releases (3.2.4 and 3.2.8) carry the same features plus further fixes, so there is no reason to stay on 3.2.1.
