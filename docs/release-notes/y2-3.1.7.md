# Innioasis Y2 Firmware 3.1.7

*Build date 1 June 2026 · Published 22 June 2026 · Android 4.4.4 · Y2 hardware*

The update the Y2 launched with, and the biggest single jump over the Y1: a lighter default look, a real file manager, deeper theme support, and proper music and video settings.

## What's in this update?

- **A lighter default theme.** The Y2's built-in HoloPebble now uses a pastel light appearance with dark status bar text, so the home screen is readable in daylight and no longer looks like the Y1. Y1 owners are not left out — the original dark look ships as a fifth bundled theme, **Classic**.
- **A file manager on the device.** Browse internal storage and the TF card, copy, cut, delete, rename and inspect file properties, sort the list, show hidden files, show file extensions, and format internal storage or the TF card without a computer.
- **Music improvements.** A dedicated music settings screen controls how song names are displayed and how the library is sorted, with separate artist and album views. Playlists can now be imported from M3U files and matched against the music on the card, and exported back out.
- **Video improvements.** Speed playback from 0.5× to 2.0×, a choice between hardware and software decoding when a file refuses to play, configurable short and long press actions for previous/next (including seek jumps and continuous seek), loop mode, auto-stop, subtitle loading, and custom scan paths so only the folders you want show up.
- **Screen-off button behaviour.** A new setting decides what the buttons do while the screen is off: Full Lock (only power works) or Media Mode (play/pause, previous and next still work).
- **Fewer storage surprises.** The player offers to rescan after the storage changes, warns you when a TF card is damaged, and caps bulk selections at 10,000 items so large libraries stay responsive.

## For theme creators

3.1.7 is a major theme update:

- Themes can now define a **File Manager** icon, bringing the home screen to 13 slots.
- Selected states can use true **nine-patch (`.9.png`) images**, which is how Melody Munchkin and Classic draw their selection bars.
- Themes can set **font scaling** (default 1.1, with Melody Munchkin using 1.0).
- Theme names are now length-checked, and pure black or fully transparent wallpapers are rejected with a clear message instead of producing an unreadable screen.

## Good to know

- This build has **no FM radio** on the home screen and a single flat settings list — those arrive in 3.2.0.
- Speaker on/off, headphone gain, wheel sensitivity and album art style are also not in this release.
