# Innioasis Y1 Firmware 3.0.2

*Published 12 December 2025 · Android 4.2.2 · Type A Y1 hardware*

A short, focused update: the Y1 now asks you to pick a language the first time it starts, and the rest of the release is under-the-hood polish.

## What's in this update?

- **Language setup on first start.** A new language screen appears on first boot and after a factory reset, so a fresh or reset player is no longer stuck in whatever language the firmware was flashed with. Pick your language once and the setup screen stops appearing.
- **Performance and stability improvements.** General responsiveness and reliability work across the player, with no visible change to the menus.

## For theme creators

The theme format is unchanged from 2.8.2. Themes built for 2.8.2 work as-is, and the three bundled themes stay the same.

## Good to know

- Type A Y1 hardware only.
- Because the theme format did not change, there is no reason to rewrite existing themes for this build.
