# Innioasis Y1 Firmware 2.1.9

*Published 18 July 2025 · Android 4.2.2 · Type A Y1 hardware*

The update that turned the Y1 into a customisable player: themes arrive, video playback arrives, and the library gains the sorting and cleanup tools people had been asking for.

## What's in this update?

- **Themes for the first time.** The Y1 gains a theme engine, a Theme entry in Settings, and a `/Themes/` folder on storage. Themes are plain folders with a `config.json` that describes the home screen, icons, colours, dialogs and menus — which is what every theme in this gallery is built on.
- **Three themes included.** The dark **HoloPebble** becomes the default look, joined by bundled **HoloBubble**, **Unseen** and **Melody Munchkin** themes you can switch between without downloading anything.
- **A real video player.** Videos joins the home menu with sections for All Video, Folders, Playlists and Search, plus a Remove Video action so you can clean up files from the device itself.
- **Library and settings improvements.** A file-extensions toggle, a clear-cache action, Spanish language support, sorting and deletion options for songs, albums and artists, favourite channels in FM radio, and lyric labels while playing.
- **A tidier, more consistent UI.** Menus, dialogs and the player screen are now all described by the theme files, so the whole interface changes with the theme instead of only the wallpaper.

## For theme creators

Firmware 2.1.9 defines the first theme format: home screen layout (nine icon slots including the Shuffle shortcut), item and dialog styling, menu and file-browser styling, player screen styling and status bar styling. The `fontScale`, nine-patch selection background and File Manager slots found in later Y2 themes do not exist yet.

## Good to know

- 2.1.9 only runs on **Type A** Y1 hardware. Do not install it on Type B scroll-wheel units.
- Themes must live in the `/Themes/` folder with a valid `config.json`; malformed themes are ignored rather than crashing the player.
