# Innioasis Y1 Firmware 3.1.2

*Published 16 July 2026 · Android 4.2.2 · Type A Y1 hardware*

The final Y1 stock release, and the one to be on. It fixes the Bluetooth problems that made modern earbuds unreliable on the Y1.

## What's in this update?

- **AirPods and modern Bluetooth headsets work properly.** Pairing and playback connection handling has been reworked for AirPods Pro 2, AirPods 3 and other newer headsets, including the case where two devices were competing for the connection and the player gave up. Audio no longer drops to the internal speaker mid-track as often, and reconnecting after walking out of range is more reliable.
- **Everything from 3.0.7 and earlier** is included: video playback, the e-book reader, the launcher selector, first-boot language setup and the four bundled themes HoloPebble, HoloBubble, Unseen, Melody Munchkin and HoloFacet.

## For theme creators

3.1.2 is the last word on the Y1 theme format, and it is deliberately narrower than the Y2 format:

- Themes use `config.json` in a folder under `/Themes/`, exactly as in 2.1.9 through 3.0.7.
- Nine-patch (`.9.png`) selection backgrounds are **not** supported; use plain images for selected states.
- There is no per-theme font scaling, no native-icon fallback toggle and no File Manager slot, because the Y1 has no File Manager.
- Every theme in this gallery that targets the Y1 is built to this format, so a theme that looks right on 3.0.7 looks right here too.

## Good to know

- Type A Y1 hardware only. Installing this on a Type B scroll-wheel unit disables the wheel.
- If you are on 2.8.2 or newer, themes carry over with no changes; only the Bluetooth behaviour changes.
