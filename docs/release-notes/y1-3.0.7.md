# Innioasis Y1 Firmware 3.0.7

*Build date 13 March 2026 · Published 23 April 2026 · Android 4.2.2 · Type A Y1 hardware*

A fourth built-in theme and a more finished e-book reader. 3.0.7 is a comfort update rather than a redesign — the interface you know, with more choice and fewer rough edges when reading.

## What's in this update?

- **New built-in theme: HoloFacet.** A fourth theme joins HoloPebble, HoloBubble, Unseen and Melody Munchkin, so you can change the entire look of the player without installing anything from the gallery.
- **E-book reader promoted and polished.** Reading is now presented as a headline feature rather than a hidden extra, and bookmarks gained proper Unread and Empty states so an empty bookmark list looks intentional instead of broken.
- **Small consistency touches around reading and the library**, keeping the reader in line with the rest of the player.

## For theme creators

The theme format is unchanged from 2.8.2, so existing themes keep working. This build simply bundles one more theme (`theme4`, HoloFacet) alongside the original three.

## Good to know

- Type A Y1 hardware only.
- If you want the newest Y1 Bluetooth behaviour, 3.1.2 is the later release; 3.0.7 is otherwise the same feature set.
