# Innioasis Y1 Firmware 1.7.6

*Build date 7 April 2023 · Android 4.2.2 · For Type B (scroll-wheel) Y1 hardware*

This is the earliest Y1 firmware kept in the community archive, and the build that shipped before themes, video playback and the e-book reader existed. It is worth knowing as a baseline, and it is the firmware to go back to on Type B units.

## What's in this update?

- **Home menu with eight items:** Now Playing, Music, Audiobook, Photos, FM Radio, Bluetooth, Settings, and a Shuffle shortcut that jumps straight into shuffled playback.
- **One plain settings list:** Shutdown, timed shutdown, shuffle and repeat modes, equalizer, sort by and sort order, key lock, key tone, key vibration, wallpaper, backlight, brightness, battery display, date & time, language, factory reset and About — all on a single screen with no categories.
- **The original player experience:** music and audiobook playback with equalizer presets, photo viewing, FM radio and Bluetooth, exactly as the Y1 shipped.
- **No theme support at all.** There is no theme engine, no theme picker, and no `/Themes/` folder, so Y1 themes from this gallery cannot be installed on this build.

## Good to know

- This firmware is built for **Type B** Y1 hardware. Type B units have the older scroll wheel, and installing the Type A 2.0.0-or-newer firmware on them stops the scroll wheel from working.
- If you are on this build and want themes, video playback or the e-book reader, you need a Type A unit on 2.1.9 or newer.
