Innioasis Y1 and Y2 theme compatibility

A theme is a skin, not firmware. On the Innioasis Y1 and Y2, one theme format is shared by Better-Y, Koensayr, Solar and the Original Software, so a theme from this gallery works on any of them. Rockbox is the one exception.

Compatibility at a glance

Player software Uses the gallery theme format? Where to browse
Original Software (stock Innioasis) Yes Themes Gallery

Why one theme works on four different software builds

The software controls how the player behaves: how it boots, how it reads files, what features it has. The theme controls how the interface looks. Innioasis and the community builds kept the same theme format across the Original Software, Better-Y, Koensayr and Solar, so the theme layer is interchangeable even though the software underneath is not.

That means the gallery does not need four copies of every theme, and you do not need to re-download your favourites when you change software. A theme you installed under Better-Y is still selectable after installing Koensayr, and the other way around.

Rockbox is not part of that group. Rockbox themes have their own file layout and installation path. A Rockbox theme will not appear in the shared theme picker, and a shared gallery theme will not load in Rockbox.

Innioasis Y1 and Y2: the same collection

The Y1 and Y2 are both covered by the same gallery catalogue. Theme pages list the players a theme is intended for and call out device-specific artwork. If you are moving a theme between a Y1 and a Y2, start from the theme's own page rather than an old download, so you get the current file and any notes from the author.

Other Innioasis and Timmkoo players

Some other Innioasis and Timmkoo players run software from the same family and can read the same theme format. Compatibility there depends on the player's software and screen, not on the gallery: a theme made for the Y1's screen may look stretched or cropped on a player with a different display, even when the format loads. Check the software name on the device first, then preview the theme at its listed size.

The firmware archive is the place to confirm which software a model runs and which build is current.

How to tell which software your player runs

  • The boot screen or About screen usually names the build; look for Better-Y, Koensayr, Solar or the stock Innioasis name.
  • Solar adds its own theme browser and Wi-Fi features, so its menus look different from the stock player.
  • Rockbox has a distinctly different interface and its own settings menu. If you see Rockbox, use the Rockbox collection.

What a theme can and cannot change

A theme can change colours, icons, backgrounds, fonts and the arrangement of the interface. It cannot change the software version, add features, alter the firmware or touch your music library. If a theme looks wrong after a software update, re-select it on the player; if it still looks wrong, check the theme page for an updated file.

Compatibility questions

Are all Y1 and Y2 themes compatible with every firmware?

With Better-Y, Koensayr, Solar and the Original Software, yes: they share the format. Rockbox is the exception.

Do the same themes work on the Y1 and Y2?

Yes. The gallery keeps one collection, with notes where a theme is tailored to one device.

Will a theme from another Innioasis or Timmkoo player work?

It can, if that player runs the same software family and format. Screen size and layout still matter, so preview before installing.

Can I switch software without losing my theme?

Yes. The theme is a separate file and stays available when you change between Better-Y, Koensayr, Solar and the Original Software.
