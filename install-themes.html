How to install a theme on the Y1 or Y2

These steps are for the Original Software, Better-Y, Koensayr and Solar. Rockbox uses its own theme pack.

On a computer

  1. Open the gallery and download the theme.
  2. Unzip it if the download is a zip. You want the theme folder, with its pictures and config inside.
  3. Connect the Y1 or Y2 and open its themes folder.
  4. Copy the theme folder in. Eject the player and pick the theme on the device.

Direct Install via USB

Chrome and Edge on a computer can hand the folder to the site. On the theme page, choose Direct Install via USB and select the player's themes folder. The link appears only when the browser supports that.

Y1 and Y2

Use the same theme folder on either player. A theme you installed on a Y1 is the one you copy to a Y2, as long as both are running one of the four systems above.
