O Innioasis Y1 i Y2 Theme Studio

Innioasis Theme Studio is the official browser-based theme maker, theme editor, and skin creator for Innioasis Y1 i Innioasis Y2 players running Original OS, Better-Y, Solar, or Koensayr.

  • Full Y1 & Y2 support: Edit Home icons (including the Y2 File Manager icon), Y2 categorized Settings icons, item backgrounds, right arrows, wallpapers, masks, custom fonts, and menu colors.
  • 1:1 live firmware simulator: Switch between Both, Y2, and Y1 layouts with authentic Android .9.png nine-patch rendering and click-to-edit selection.
  • Try on Device & publish: Export a ready-to-install ZIP, copy directly to your player over USB, or publish straight to the Galeria motywów Innioasis.

The variation leaves the theme you are editing, and the next save or submission leaves it out. If the gallery already lists it, the removal is applied when that update is merged.

A variation is another look for the same listing — Pip-Boy ships seven, Stranger Things several. Your edit starts from the version on screen, and saving or submitting stores it under Variants/<name>/.

Both copies use the same theme and the same files. this theme draws Bluetooth differently on each player — a Home icon on Y1, a Settings icon on Y2 — so the ZIP you install gets the artwork your player looks for.

Tryb pamięci USB

Wypróbuj ten motyw na swoim odtwarzaczu

Skopiuj bieżący motyw ze Studia prosto do folderu odtwarzacza Themes przez USB, abyś mógł od razu przetestować go na prawdziwym sprzęcie.

Testujesz ponownie w tej sesji?

Po bezpiecznym odłączeniu pamięci USB uruchom ponownie odtwarzacz i wybierz inny motyw (a potem wróć do niego), aby odtwarzacz wyczyścił pamięć podręczną i wczytał zaktualizowane pliki.

  1. 1
    Włącz tryb pamięci USB na odtwarzaczu

    Podłącz Innioasis Y1 lub Y2 przez USB i włącz Tryb pamięci USB na odtwarzaczu, aby jego pamięć pojawiła się na komputerze.

  2. 2
    Kliknij „Wybierz folder Themes”

    Wybierz Themes na swoim odtwarzaczu. Studio skopiuje your theme bezpośrednio do niego w celu przetestowania.

Bezpośredni dostęp do folderu USB nie jest dostępny w tej przeglądarce

Wybieranie folderu odtwarzacza Themes bezpośrednio wymaga desktopowej przeglądarki opartej na Chromium (Chrome, Edge, Brave lub Opera) przez HTTPS. Nadal możesz zapisać plik ZIP motywu na urządzeniu i skopiować rozpakowany folder do katalogu odtwarzacza Themes folder.
