বিষয়বস্তুতে যান

সমস্যা সমাধান এবং ডিভাইস পুনরুদ্ধার

MTKক্লায়েন্ট ফ্ল্যাশিংয়ের পরে একটি নন-বুটিং ডিভাইস পুনরুদ্ধার করা

যদি আপনার Innioasis Y1, Y2, বা MediaTek ডিভাইসটি চালু করতে ব্যর্থ হয় বা macOS বা Linux-এ MTKclient এর সাথে ফ্ল্যাশ করার পরে একটি কালো স্ক্রিন দেখায়, তাহলে আতঙ্কিত হবেন না। হার্ডওয়্যার বুটরম (BROM) স্থায়ী এবং ধ্বংস করা যাবে না।

কেন MTKক্লায়েন্ট একটি কালো স্ক্রীন স্টল বা ছেড়ে যেতে পারে

MTK ক্লায়েন্ট DA প্রমাণীকরণকে বাইপাস করতে এবং libusb-এর মাধ্যমে অশোধিত USB যোগাযোগের জন্য সফ্টওয়্যার এক্সপ্লয়েট পেলোড (কামাকিরি / অ্যামোনেট) এর উপর নির্ভর করে macOS এবং Linux ARM64 সিস্টেমে:

  • USB ম্যাকওএস-এ হ্যান্ডশেক লেটেন্সি বা পোর্ট টাইমআউট DA পেলোড ইনজেকশন মাঝামাঝি স্থানান্তরকে আটকাতে পারে।
  • অনুপস্থিত বা অসম্পূর্ণ পার্টিশন হেডার বুটলোডার (প্রিলোডার/lk) একটি অ-প্রতিক্রিয়াশীল অবস্থায় রেখে যায়।
  • প্লেয়ারটি সম্পূর্ণরূপে মৃত বলে মনে হচ্ছে - LED নেই, চার্জিং আইকন নেই, স্ক্রিন ব্যাকলাইট নেই।

এমনকি এই অবস্থায়, MediaTek চিপসেট ফিরে আসে ব্রম মোড (USB VID 0e8d, PID 0003), অফিসিয়াল নিম্ন-স্তরের পুনরুদ্ধারের জন্য প্রস্তুত।

দ্যা ডেফিনিটিভ রিকভারি মেথড: SP Flash Tool ইঞ্জিন ইন আপডেটার সিই

আপনার ব্রিক করা প্লেয়ারটি পুনরুদ্ধার করার সবচেয়ে নিরাপদ, সবচেয়ে নির্ভরযোগ্য উপায় ব্যবহার করা হচ্ছে আপডেটার CE কর্মকর্তার সাথে কনফিগার করা হয়েছে SP Flash Tool ব্যাকএন্ড

আপডেটার সিই-তে সঠিক পদক্ষেপ:

  1. খোলা আপডেটার CE.
  2. ক্লিক করুন সেটিংস বাম নেভিগেশন সাইডবারে।
  3. উন্নত বিভাগে নিচে স্ক্রোল করুন এবং সক্ষম করুন উন্নত সেটিংস দেখান.
  4. অধীন ইন্সটল পদ্ধতি (বা MediaTek ইনস্টলারের জন্য ফ্ল্যাশিং ইঞ্জিন), সনাক্ত করুন ফ্ল্যাশ পদ্ধতি ড্রপডাউন
  5. থেকে নির্বাচন পরিবর্তন করুন স্বয়ংক্রিয় (প্রস্তাবিত) বা MTKClient থেকে SP Flash Tool.
  6. প্রম্পট নিশ্চিত করুন এবং প্রধান ইনস্টল প্রবাহে ফিরে যান।

SP Flash Tool এর জন্য প্ল্যাটফর্ম আর্কিটেকচার এবং ওএস প্রয়োজনীয়তা

MediaTek এর অফিসিয়াল SP Flash Tool বাইনারি একটি হিসাবে স্থানীয়ভাবে কম্পাইল করা হয় লিনাক্সের জন্য x86_64 ELF বাইনারি এবং ক PE32+ Windows x64 এর জন্য এক্সিকিউটেবল.

macOS এবং ARM64 লিনাক্স ব্যবহারকারীদের জন্য গুরুত্বপূর্ণ হার্ডওয়্যার নোট:
কারণ MediaTek macOS (ডারউইন) বা Linux ARM64 (aarch64) এর জন্য SP Flash Tool কম্পাইল করে না, macOS ব্যবহারকারী এবং ARM64 লিনাক্স ব্যবহারকারীদের (যেমন Raspberry Pi বা Apple Silicon চলমান Asahi Linux) একটি ইটের অভিজ্ঞতা তাদের প্লেয়ারের সাথে সংযুক্ত করতে হবে:
  • আ x64 উইন্ডোজ পিসি (উইন্ডোজ 10 / 11 64-বিট), বা
  • আ x86_64 লিনাক্স পিসি (উবুন্টু, ডেবিয়ান, ফেডোরা, আর্চ 64-বিট)।

ধাপে ধাপে হার্ডওয়্যার আনব্রিকিং প্রক্রিয়া

  1. প্লেয়ার সংযোগ বিচ্ছিন্ন করুন: প্লেয়ার এবং পিসি থেকে USB কেবলটি সম্পূর্ণভাবে আনপ্লাগ করুন।
  2. হার্ড পাওয়ার বন্ধ: চিপসেটটি সম্পূর্ণভাবে চালিত হয়েছে এবং কম-পাওয়ার USB লুপে আটকে নেই তা নিশ্চিত করতে পাওয়ার বোতাম (বা পাওয়ার + ভলিউম ডাউন) 15 সেকেন্ড ধরে রাখুন।
  3. SP Flash Tool মোড সহ আপডেটার CE চালু করুন: আপনার ডিভাইস মডেল নির্বাচন করুন (যেমন Innioasis Y1 বা Innioasis Y2) এবং চয়ন করুন মূল সফটওয়্যার স্টক পার্টিশন পুনরুদ্ধার করতে।
  4. ইনস্টল / পুনরুদ্ধার শুরু করুন: ক্লিক করুন ইনস্টল / পুনরুদ্ধার আপডেটার সিইতে। স্ট্যাটাস প্রম্পট না বলা পর্যন্ত অপেক্ষা করুন খেলোয়াড়ের জন্য অপেক্ষা করছি...
  5. BROM ট্রিগার করার জন্য USB কেবল ঢোকান: ডিভাইসটি বন্ধ থাকা অবস্থায়, একটি উচ্চ-গতির মাদারবোর্ড USB পোর্টে সরাসরি USB তারের প্লাগ ইন করুন (পাওয়ারবিহীন USB হাব এড়িয়ে চলুন)।
  6. সিস্টেমটি MediaTek VCOM পোর্ট শনাক্ত করবে, ডাউনলোড এজেন্ট (DA) চাপবে, পার্টিশন টেবিল পুনর্লিখন করবে এবং সমস্ত ফার্মওয়্যার ছবি পরিষ্কারভাবে পুনরুদ্ধার করবে।
